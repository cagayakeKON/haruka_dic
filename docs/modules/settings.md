# 个人设置、模型凭据与客户端缓存

状态：设计基线 v0.2；[B2a本人资料与设置](../delivery/reviews/2026-09-28-profile-settings-acceptance.md)在原视觉通过结论因正式UI偏离已确认Flutter mock而撤回后，已把真实功能接入同一主界面并经正式Web/Android及隔离PG定点复核，按当期范围重新验收通过。本人资料、学习档案、显示/阅读/查询预算偏好由 `/users/me/profile`、`/users/me/study-profile`、`/users/me/settings` 读写，已登录应用的设置页走这三组接口。显式登录后若 `profile_completeness` 仍缺显示名、解释语言、学习语言或时区，会进入可跳过引导；跳过不提交、不在本机记下完成。头像的校验、发布和 `private, no-store` 读取在后端可用；已登录设置页按当前资料指针读取本人 JPEG，并在有 `profile.avatar.update` 时用同一按钮提交意图与完成请求。预览页的头像按钮仍只切换字形。Windows/Android 可在登录前或设置里探测新的 HTTPS 服务地址；确认后才退出当前实例、清理本机缓存并改指向，探测不带旧凭据，连接失败保持未登录。确认后的地址保存在本机，下次启动继续使用，且不写入遥测。Web 只显示当前部署地址。B2c模型凭据、L4媒体本机容量配额及其消费者仍未交付；B2a只保存当期阅读/查询偏好，不冒充后续业务已消费。注册/登录/改密/设备会话以 [账号流程](accounts.md) 为准，身份/权限/离线限制以 [认证与隔离](../architecture/authentication.md)、[RBAC](../architecture/authorization.md) 为准。字段契约见 [API 契约](../contracts/api.md)。

DESIGN20已确认小说章节的提前下载：在章节入口多选解析/朗读，单项或双项，生成完成后提前缓存到当前账号设备；暂停/继续和失败重试包含该受控章范围。现有容量/清理/离线租期继续适用，具体状态见[章节准备契约](../contracts/novel-preparation.md)；全局下载中心、固定保留等管理增强仍为P1，不能将已确认章节能力整体推迟到P1。

DESIGN24材料上传与正式NLP暂限日语/英语；母语、解释语言和中文UI不扩大材料白名单。日语分词固定SudachiPy B中粒度，英语固定spaCy，设置界面不增加A/B/C粒度或引擎选择，详细能力边界见[文本分析](../architecture/text-analysis.md#11-已确认的日英nlp适配)。

## 1. 范围、入口与权限

DESIGN23的基础NLP快照、句子/token/ruby属于既有本机文本副本容量，随正文/AI结果下载；清本机只删设备副本，重新打开从持久层取回，不重新OCR/解析/合成。用户不需要另选“是否分词”或配置另一个NLP缓存开关，详情见[统一文本分析](../architecture/text-analysis.md)。

设置入口按可用子功能展示账号资料、安全、学习语言、显示、服务连接、模型与 Key、阅读、朗读、单词数据和本机缓存。没有 profile 权限时不返回整份个人配置，仍保留经过身份验证的本人安全/退出入口；权限快照不得因设置页不可见就无法更新。首版不存在公开个人主页、关注关系或普通用户间资料搜索。

登录和缓存初始化只依赖当前受众的 me/access 返回的最小本人主体标识、instance_id、audience、session_ref 与权限版本，具体信封以 API/账号协议为准，不把 users/me 或 settings 的 profile.read 当所有账号启动前置条件。有 profile.read 才并行读取个人资料/偏好；没有时使用安全的界面默认值，仍可进入有权页面或受控空状态。最小主体标识用于绑定 AccountScope，不返回完整个人资料或任何会话凭据。

| 子功能 | 权限/范围 | 持久化与边界 |
| --- | --- | --- |
| 登录身份摘要 | 账号流程的本人身份基础读取 | 当前登录邮箱、验证/账号状态和创建时间只读展示；不依赖profile.read，首版不能从资料PATCH修改邮箱 |

| 学习档案/基础偏好 | client.profile.read/update | user_extensions中的学习/设置字段组独立revision；母语、解释语言、目标语、当前目标语、水平/目标、时区与显示默认值 |

## 2. 流程、状态与异常

### 2.1 服务地址与实例切换

Windows/Android 在登录前可配置 Haruka 服务地址，登录后更换地址视为切换服务实例。只接受经过校验的 HTTPS base URL，拒绝用户名/密码、query、fragment 和不允许的协议；开发 HTTP 例外只存在明确的开发配置，不由发布版“忽略证书错误”开关解决。服务地址不是供应商 base_url，不能提交给后端变成任意 HTTP 代理。

正常流程：输入地址 → 独立无凭据连接探测 → 展示服务身份/版本/兼容性 → 确认使用 → 登录。建议公共 `GET /api/v1/meta` 返回 instance_id、服务名、版本/最低客户端版本和非敏感能力标识；实际结构由 API 契约登记。探测不发送当前账号 Cookie/Bearer/个人 Key，不因相同邮箱假设两实例共享账号。

Web 推荐固定同源部署，显示当前服务地址和连接状态；不在运行中的 Web 应用里任意更改 API origin 并转发 Cookie。使用其他部署通过打开该部署的独立地址完成并重新登录，不能绕过 CORS/CSRF 或将 MyHome 会话当 Haruka 会话。

登录后的切换先提示“将退出当前实例并清理本机该账号缓存”，停止新操作，尽力撤销原会话，随后本地清理并增加账号代次；远端撤销失败按账号流程明确提示，不阻止本机清理。连接新实例失败保持未登录状态，不恢复旧明文凭据或把旧请求自动改发新地址。缓存分区绑定经确认的 instance_id 与规范化地址，不仅按邮箱命名。

### 2.2 Key 保存、测试、轮换与删除

#### 保存

1. 界面明确 Haruka 不将材料用于自身训练，并说明本次能力将向所选供应商发送什么内容；供应商保留/训练政策以其已核对的说明为准，不代其作未验证的保证。选择 provider；首版允许配置的入口为 OpenRouter 与 Gemini 直连，具体默认值仍待确认。界面说明文本/视觉/TTS 可能需要不同能力，Key 本身不代表所有模型都可用。
2. 输入 Key 时默认掩码，可临时显示/粘贴；不回显旧 Key、不自动填入浏览器持久表单/普通偏好，不写错误日志、分析事件或崩溃上下文，应用不主动复制到剪贴板。UI 完成/离开即释放其受控输入状态，不声称能保证运行时字符串内存物理擦除或清除操作系统已有的剪贴板历史。
3. 点击“保存”经 HTTPS 提交到本人 credential 服务，校验允许 provider/长度与权限，不调用模型。保存和测试是两个操作；保存只证明已加密持久化，状态显示 untested，而不是“连接成功”。
4. 后端用部署 Secret 中独立主密钥封装加密，保存 owner、provider、密文、credential_version、encryption_key_version、revision、状态与掩码。credential_version 是用户供应商 Key 的更换/撤销代次；encryption_key_version 仅引用部署加密 Keyring 的主密钥版本；row revision 独立用于并发更新。密文和明文都不作为 API 响应、Job 参数或日志属性，任务只保存本人 credential_id 与必要的安全版本引用。
5. 返回掩码/标识和 revision，客户端清除 Key 输入。默认模型配置可绑定该 credential_id；另一账号伪造 ID 时不返回其存在或掩码。

#### 能力测试

B2c的正式能力测试采用持久Job异步受理，202返回job/run引用，经本人凭据测试结果接口读取安全状态；任务WebSocket另验job.read及来源。刷新/重连只读已有结果，不重新测试，具体路径见[API](../contracts/api.md)。

测试按钮要求 credential.test；用户选择文本/视觉/TTS 中要验证的一项，显示会发送的固定最小样本、调用次数和可能消耗供应商用量。不得点击一个通用“检测”就悄悄调用三种能力。测试通过当前用户的同一模型工厂/音频适配器和调用上限约束，有单独 operation_id；不使用用户私有整章材料作探测输入。

结果包含本次 provider/model/capability、配置版本、tested_at、成功/失败类别和安全用量。失败区分 Key 拒绝、模型不可用、能力不符、额度不足、限流、网络故障、格式错误；不返回供应商请求完整转储。网络失败不自动将凭据永久标 invalid；模型/声音失败也不代表同一个 Key 的其他能力都无效。测试结果是某时刻该组合可用，不保证未来请求成功。

#### 轮换与删除

更新/撤销供应商 Key 使用 expected_revision，成功推进 credential_version，清理本账号旧解密客户端/配置缓存；新密文写入当前有效 encryption_key_version。新供应商调用阶段只读取当前有效 credential_version，不拿它查部署主密钥。已经开始的外部调用不能承诺撤回，在途返回按 [数据与任务](../architecture/data-jobs.md) 的最低限度保存/清理处理。普通设置更改不批量重新合成音频或重评分。

删除前显示受影响的文本/视觉/TTS 绑定及尚未完成任务数；确认后将凭据不可用并删除密文或进入受控密钥删除策略，解绑当前选择。等待执行的模型调用任务进入可恢复的 blocked/Key-required 状态；恢复需要用户配置新凭据并显式继续，不自动借用另一个 Key。已经保存的解释、题目、音频、答卷保留，按各自权限可读；删 Key 不等于删除这些成果。

并发轮换/删除冲突返回当前 revision 和安全状态，保留用户本次输入直到其选择重试/放弃，不能在响应中重发旧明文。主密钥运维轮换重加密密文并更新 encryption_key_version，不改变供应商秘密含义或 credential_version，也不触发模型测试/重新合成；该迁移与用户更换 Key 使用独立版本比较和并发保护。主密钥不能作为用户设置页字段，运维/归档密钥保留规则见 [配置与运行](../operations/configuration.md)。

### 2.3 个人资料、学习档案与首次引导

注册只建立一个空UserExtension；UserProfile/StudyProfile/Settings仍是独立API投影，物理字段同在user_extensions，分别用profile_revision/study_revision/settings_revision；首次登录引导与设置页写入同一组API和revision。引导可跳过，不以页面埋点或本机布尔值标记完成；服务端根据当前字段计算 `profile_completeness`，并只在需要相关字段的功能入口提示补全。资料保存不要求模型Key，也不能隐式创建材料、习题或模型调用任务。

#### 字段与用途

| 字段组 | P0字段 | 规则与用途 |
| --- | --- | --- |
| 基本显示 | `display_name` | 可空、非唯一、Unicode限长；仅作为本人界面称呼，不是登录标识、公开用户名或授权依据。空值显示本地化“学习者”，不从邮箱前缀公开推导 |
| 头像 | `avatar_asset_id/avatar_revision` | 可空；只引用本人已验证的AvatarAsset。无头像显示通用图标；删除只解除当前头像并按引用规则回收旧资产 |
| 年龄信息 | `birth_year` | 可空，UI称“出生年份（可选）”；服务端只校验合理年份并按当前日期派生粗粒度年龄段，不保存会过期的整数年龄，也不要求完整生日。不能决定登录、权限、分数或掌握状态 |
| 性别 | `gender_code`、可选 `gender_self_description` | 可空；代码为unspecified/female/male/non_binary/self_described/prefer_not_to_say。自定义说明限长，可清除；不用于权限、评分或默认Prompt |
| 语言档案 | `native_languages[]`、`explanation_language` | 有序、去重的受支持BCP-47标签；解释语言须在后端发布的可用解释语言中。母语可多个，不等同UI语言 |
| 学习语言 | `target_languages[]`、`active_target_language` | P0学习目标只允许已发布的英语/日语能力；当前语言必须属于目标语。没有目标语仍可登录/看设置和已有数据，需要语言的功能单独提示 |
| 单语设置 | 每个目标语的 `self_assessed_level`、`learning_goals[]` | 水平为unknown/beginner/elementary/intermediate/advanced；目标从阅读、教材、考试、听力、口语、写作、词汇、语法受控选择。仅用于默认筛选/建议，不伪造测评、解锁权限或修改掌握 |
| 地区/时间 | `timezone` | IANA时区，设备仅建议、用户确认后保存；用于日期展示和统计/选择边界，历史仍存UTC，不改变考试截止、会话期限或冻结快照 |
| AI资料使用 | `use_optional_demographics_for_ai` | 默认false；只有用户打开且具体功能明确需要时，才可把派生年龄段/性别作为本人模型上下文。头像、出生年份原值和自定义性别说明不发送；母语/目标语按功能必要性独立使用 |

P0界面语言仍为 `zh-Hans`，它与母语、解释语言、目标学习语言分开。语言选项来自后端版本化能力目录，返回 `ui_supported/learning_supported/explanation_supported` 等安全标识；客户端不能提交任意字符串并假设模型支持。移除目标语只改变默认入口/筛选并清除该语言的active状态，不删除该语种材料、收藏、作答、错题、诊断或模型结果；重新加入后仍读取原历史。

#### 更新与隐私边界

资料、学习档案、通用设置按各自 `expected_revision` 映射同一扩展行的字段组版本，使用字段白名单和field mask更新，未知/只读字段拒绝。只写目标组列并递增该组版本，不整行保存旧DTO；同组旧版本冲突，不同组短暂串行但不相互制造版本冲突。一个页面保存失败不回滚另一个已成功提交的独立聚合；同聚合多端冲突返回当前revision和允许披露的字段类别，客户端保留草稿并让用户重新应用，不做last-write-wins。可选字段均支持显式清除；清除出生年份/性别会停止后续可选个性化，不重写已经完成的历史AI结果。

个人资料默认只有本人 `client.profile.read` 可读。管理端 `admin.user.read` 继续只读账号运维所需的邮箱、显示名、状态和安全元数据，不默认返回头像原图、出生年份、性别、自定义说明、母语/目标语、学习水平或偏好；需要此类跨用户能力必须新增明确产品范围和权限。普通用户不能通过头像ID、资料revision、日志或缓存探测他人资料。

#### 头像上传、替换与删除

P0接受JPEG/PNG/WebP静态图片，初始硬上限建议5MiB、4096×4096，最终值由配置和实际三端样本锁定；拒绝SVG、动画、伪造Content-Type、解码失败、超限尺寸及外部URL。客户端可裁剪预览，但服务端必须在受限CPU/内存/时间的处理环境中按实际字节解码，先限制总像素和帧数，再移除EXIF/定位等元数据并重编码成受控正方形派生图，不能原样公开用户文件。

Windows/Web使用系统文件选择器，Android使用系统图片选择器；P0不为头像申请相机权限，未来增加现场拍照需单独验证权限与临时文件清理。三端裁剪只是预览建议，不能替代服务端重新处理；选择或裁剪失败保留旧头像并允许重试。

流程为申请本人avatar用途的临时UploadIntent → 直传staging对象 → 完成接口验证摘要/大小/解码 → 发布不可变AvatarAsset（purpose=avatar的FileObject专用投影）→ 在profile_revision事务中替换当前指针。重复完成/重试只发布一次；过大、格式不支持、解码失败和revision冲突使用稳定错误码分别反馈，任何失败都不改变旧头像，孤立临时对象按期限回收。删除头像只提交资料指针变更，旧资产在没有活动资料/审计保留引用后受控GC。

当前实现的完成请求是 `application/json`，正文为 `expected_revision` 与标准 base64 的 `image_base64`，从而沿用现有 JSON 写保护。图片格式以上传意图中的 `declared_format` 对照实际魔数，不一致、SVG、动画、解码失败或超限都不替换旧头像。预签名直传、材料对象存储和容量预留账本尚未接入；成品字节与 `file_objects` 同行保存，`GET /users/me/avatar` 在每次会话和 `profile.read` 校验后返回，并固定 `Cache-Control: private, no-store`。重复完成只发布一次。删除只清空资料指针，并把旧对象标为延迟回收。

头像读取每次经过当前会话和profile.read校验，P0响应固定使用 `Cache-Control: private, no-store`，不发送可被共享/浏览器HTTP缓存复用的长期URL或仅按数字revision生成的跨账号ETag。Windows/Android在成功鉴权取得字节后可维护应用管理的副本，Web首版只用当前AccountScope内存副本；两者都按instance/user/avatar_asset摘要或avatar_revision分区并在退出、换账号、撤权或revision变化时失效。同一路径 `/users/me/avatar` 从A切到B必须重新请求并显示B或空头像，不能命中A的浏览器缓存；缓存优化若以后改用条件请求，必须另立owner绑定验证器、重新鉴权和撤权语义。

### 2.4 模型、语言与阅读/朗读偏好

DESIGN22在设置中增加独立的“查询与上下文”，默认10000 tokens，可用快捷值或自定义设置；字段、预算含义和范围唯一见[查询上下文契约](../contracts/query-context.md#1-预算设置)。保存只影响下一次查询，在途任务冻结原设置；历史解释不会因此重生成。朗读设置先选已适配的具体模型，再显示对应声音、语种和有效参数；切模型不能保留不兼容声音或无效参数，协议见[每模型适配器](../architecture/tts-adapters.md)。播放倍速与本机格式转换复用已有资产；实际供应商合成参数变化则匹配新资产，保存不生成。

| 配置组 | 字段/交互 | 生效逻辑 |
| --- | --- | --- |
| 文本 | provider、credential_id、model_id、解释语言/详细程度 | 下一个新 run 使用新 settings_revision；活动 run 保持其冻结模型参数，凭据有效性仍逐供应商调用步骤检查 |
| 视觉 | provider/模型/credential、目标语和释义语言默认 | [统一OCR/拍照识别](../architecture/vision-recognition.md)使用此配置，无传统OCR自动后备；缺Key时扫描内容待识别，模型图像支持不等于整卷质量通过 |
| TTS | provider/模型/credential、按语言声音、实际支持的合成参数 | 新请求使用新合成键；已缓存旧声音仍标识其配置，不假装已切换 |
| 收藏单词标准发音 | 已发布标准声音profile及词条读音变体，规则见[全局词音](../architecture/learning-cache.md#51-收藏库标准单词发音的全局缓存) | 默认用标准profile提升跨用户复用；显示实际配置，改个性参数未纳入标准profile时走私有缓存；未命中使用本人Key，不能借其他人的Key |
| 语言 | 引用本节个人学习档案的explanation/target/active字段 | 切换刷新以后新诊断/AI习题的默认范围，不改旧记录语言、不删除历史；字段约束只在2.3维护 |
| 时区 | IANA 时区标识，初始取设备建议并允许用户确认修改 | 用于日期展示、诊断及AI习题时间筛选；后端校验，历史仍存UTC，不改变考试截止/会话期限或既有选择快照 |
| AI习题 | 默认目标语/词本、题型/方向和题量建议 | 仅预填下一次条件，仍须预览确认后才调用模型；不提供每日复习目标、到期/FSRS设置，掌握阈值/证据不可手改 |
| 阅读 | 字体类别、字号、行距、浅/深/sepia | 即时预览、保存成功后跨端使用；字体不可用使用可预期回退，不改原文锚点 |
| 应用显示 | theme_mode=system/light/dark、reduce_motion=system/on | 服务器保存本人默认值，设备可选择跟随系统。阅读sepia/正文排版仍是独立阅读偏好 |
| 朗读 | 播放倍速0.7–1.5、默认声音、模型支持的朗读风格、本机播放格式 | 风格属于合成参数且仅能力支持时可选，旧音频保持实际配置；倍速/本机格式不触发新合成，格式按TTSA/LC从已有原件派生或选择兼容版本；不支持项明确提示，不能静默换模型 |
| 解释 | 简短/标准/极客；母语或目标语说明 | 下一次解释/缓存键生效，已有解释保持原版，可显式重新生成 |

模型/声音目录从后端允许清单读取，显示 capability、是否已验证、下线/不可用信息；“管理端允许”与“本人 Key 实测可用”分开。P0 不开放用户任填供应商 URL、Prompt 代码或任意 HTTP Header；模型 ID 可以从已允许目录中选择，不让模型回答修改配置。具体默认模型和声音待技术验证，不把文档举例当永久可用项。

“模型用量”页从服务端读取本人聚合，默认按时间范围和模型分组，展示调用成功/失败/未知次数，以及供应商实际返回的input、output、cache read、cache write、reasoning、音频Token、字符或音频秒数。未知显示“未提供”，不能显示为0；应用结果缓存命中只显示为复用事件，不伪造一条零Token模型调用。字段与聚合规则只由[模型用量统计契约](../contracts/model-usage.md)维护。

界面语言/母语/目标语的字段、清除和历史规则以2.3为准。P0界面只承诺中文；其他语种能力按版本/能力目录显示，不承诺切一个locale就得到同等质量。

后端文案语言解析、客户端错误翻译、回退与异步任务语言快照统一遵循 [API 多语言约定](../contracts/api-responses.md#6-多语言与文案归属)；不能用 Accept-Language 替代学习目标语，新增 UI 翻译另行确认范围。

所有服务器偏好保存带 expected_revision。UI 可临时预览字体/颜色/倍速，但明确“未保存/保存失败”；刷新以服务器值为准，冲突展示双方变化并选择重试，不一方静默覆盖。切设置不会重复执行页面初始化的模型调用任务；权限/配额不足保存或使用时有明确业务错误。

正式业务尚未交付后台系统推送或邮件学习提醒，因此设置页不展示无效“通知开关”。当前前端预览的Android本地通知通过前台周期及已确认通知变化读取已授权站内消息，切回应用不额外发起业务刷新，并在系统通知栏显示不含私人内容的未读摘要；拒绝系统通知权限时“我的→消息”仍可使用。这不代表后台推送、渠道订阅或正式M1通知业务已经交付。以后增加后台通知或其他渠道时，先定义渠道授权、默认值、退订和失败语义。强制安全通知、运维日志与可选产品分析不能混成一个总开关；本期统一日志的必要采集遵循观测专题，不伪造“关闭后绝不产生日志”的承诺。

### 2.5 下载、清理与账号切换

DESIGN22本机缓存页分别展示“本机可用”和“已保存成果”，区分解释份数、完整音频段数及实际可得字节数；下载失败不能计本机可用。文本/音频本机容量分别设置，属于实例/账号/设备偏好，不跨端覆盖。清理后回源已有成果，无需重新使用Key；统一生命周期见[系统缓存矩阵](../architecture/learning-cache.md#9-统一读写流程与配置矩阵)。

P0 支持已读章节/已查词句解释/已生成音频的基础缓存以及“清除此账号本机缓存”。本机容量有上限，按最近使用淘汰可从服务端取回的副本，不删除服务端持久结果；正在播放/读取的文件加短期引用保护，清理时先停相关消费或延后删除，不能删到另一个服务实例/账号目录。当前P0同时实现章节入口的解析/朗读多选准备与提前下载，以及文本/音频独立容量、分项统计与清理。P1仅增加全局下载中心、跨材料队列管理、固定保留、按材料批量清理等未呈现的管理增强。

下载先写临时对象，核对长度/摘要后原子登记 ready；磁盘满、网络中断或进程结束留下的临时文件可清理，不能将截断音频当作成功。并发下载同一资产复用受控任务；切账号时取消客户端下载，旧回调经 account_generation 拒绝写入新分区。服务端独立生成 Job 保持原用户归属，普通退出不会转给新用户或自动取消。

清理流程：展示范围/容量 → 用户确认 → 停止关联播放/下载 → 清理本机索引和私有文件 → 返回已清理/失败数量。清理失败保留待清理标记并重试，不能删除任意服务器资料。只清缓存不退出；退出/换账号则清除该账号凭据、缓存、草稿、队列、订阅及临时文件，顺序和远端撤销以 [账号流程](accounts.md) 为准。

切账号/受众使用全局 AccountScope 的递增 generation。所有请求、Stream、下载、播放器、Repository 和 Riverpod 状态带创建时 generation；响应应用前检查相符，否则丢弃。Web 同源 client/admin 可有各自会话，但缓存/队列/授权仍按 audience 分区；管理页面关闭不应清掉另一个仍有效用户端会话的 Cookie，退出当前受众也不错误宣称两端已全退。

“退出全部设备”属于服务器会话撤销，不能保证远程设备上的用户副本立刻物理删除；在线设备在下一授权边界清理，离线遵守租期上限。Haruka 不提供整库 ZIP 或缓存文件恢复按钮，单词迁移仍只有 [CSV](../contracts/vocabulary-csv.md)。

## 3. 前端职责

负责按访问快照展示可用设置、头像裁剪/上传状态、语言组合约束、输入掩码、能力与调用范围提示、保存/未保存/冲突状态，以及当前账号的缓存/播放器/下载生命周期。不能把 profile.read 作为所有登录用户启动的前置权限；账号主体从 access 的最小身份取得。资料表单切布局保留未提交草稿但不自动重提上传，换账号/实例销毁草稿、头像预览和迟到响应。

### 3.1 缓存与离线显示

服务端按 [学习结果缓存](../architecture/learning-cache.md) 持久保存所有完整成功解释和TTS；客户端只保存这些结果的副本、原文和有界遥测，清理本机不删服务端结果。P0增加有效租期内已缓存词句解释的只读展示，不建立收藏/笔记/练习/设置的离线写队列。考试短时草稿仍按 [考试专题](exams.md)，不能通过缓存提前读取受限解析。

| 缓存 | 分区/有效性 | 清理影响 |
| --- | --- | --- |
| 目录/章节 | instance + user + audience + material_revision + content_id；在线本次动作校验，离线检查读权限租期 | 仅删除本机副本，下次在线按权重取 |
| 单词/句子解释与已查索引 | 同一账号/受众分区 + 源版本/选区/任务与artifact版本；来源read及ai.explain、有效离线租期 | 自动尝试保存完整已读结果；淘汰/清理只删本机副本，从服务端取回不再发起供应商调用，不把历史语境冒充当前语境 |
| 音频 | 同上用户分区 + asset/合成键/真实格式，下载校验完成才标可离线 | 不删除服务端音频，不重复发起供应商调用；可重新下载已授权对象 |
| 权限/配置快照 | 从 access 最小主体绑定实例/账号/audience/session_ref、user_authz_version/policy_revision 与服务端期限；profile/settings另按权限读取 | 非当前版本不可为在线授权；管理端不离线使用；缺profile权限不阻断身份初始化 |
| 当前页面临时输入 | 账号代次 + 业务版本，只供当前工作流恢复 | 退出/换账号销毁；未提交不能宣称已保存 |
| 遥测补传 | 实例/用户/audience/账号代次、事件白名单/TTL/容量 | 队列清理计数，不挪用为答案/笔记正文存储 |

租约由成功在线鉴权后签发/更新的服务器期限决定，推荐最长 24 小时且部署可缩短，严格依据 RBAC/账号会话的更短有效期限。客户端记录服务器时间锚点与单调计时；本地时钟回拨不能延长租约。进程重启后无法可信确定剩余期限时要求联网，不凭修改设备时间续租。不能声称客户端租约是对已拿到文件的强 DRM；它约束官方应用的授权显示。

网络不可达才可在有效租期内读已有章节/词句解释/音频，并检查各自动作与来源的快照许可；一旦服务器明确返回会话撤销/权限拒绝，不能切“离线”绕过该结果。恢复网络先验证会话和权限版本，再继续读取/下载；被删除或失权内容清缓存、停止播放器。首次登录、新内容下载、修改收藏/设置、生成/评分及管理操作都要求在线。

FCACHE1选定Riverpod + Dio + Drift/SQLite：Windows/Android采用NativeDatabase，Web采用通过验证的安全WASM持久模式；音频由独立平台BlobStore管理。完整[缓存更新机制](../architecture/frontend-cache.md)统一进入页校验、提交后失效、跨端/多标签更新、旧响应拦截、离线租期、清理/配额与升级；[校验契约](../contracts/client-cache.md)按实际来源/动作返回版本和许可。Web不安全多标签模式或无法安全协调清理时退为内存，配额回收只丢本机副本，不丢服务器学习记录。FCACHE-01～14与本篇CACHE一起按阶段验收，不能将文档选型当已交付。

本机缓存数据不等于秘密凭据仓库。刷新材料进操作系统安全存储或 HttpOnly Cookie；Key 不进 Drift。用户可以获得自己的本机数据，本项目不承诺抵御已经控制设备的攻击者；应用仍禁止跨账号复用文件/索引和日志泄漏。

## 4. 后端职责

负责user_extensions三个API字段组的白名单、字段级校验与版本冲突，头像临时上传/安全重编码/不可变发布与GC，语言能力目录，以及本人凭据的加密持久化、安全 DTO、显式单项能力测试和本人模型用量投影。provider/model/声音只从允许目录选择；不能因为能保存字符串就声称该组合已验证或将服务地址当供应商代理。

出生年份/性别属于可选个人数据，查询、备份、调试与管理DTO默认不扩大可见性；服务端计算年龄段时使用受控当前日期，不把客户端自报整数年龄当事实。只有 `use_optional_demographics_for_ai=true`、当前功能登记允许且用户仍有相应模型动作权限时，运行依赖才可取得最小派生值；日志、任务消息和AiRun不得保存这些原始字段。语言/目标等必要学习上下文仍按具体功能和来源权限注入，与该可选开关分开。

用户 Key 的 credential_version、部署主密钥的 encryption_key_version 与行 revision 分别管理，用户轮换和运维重加密并发时都不能覆盖新秘密；任务只持有本人凭据引用和必要安全版本，不保存明文。密钥生命周期、会话/租约、主密钥归档与恢复以公共架构/运维文档为准。

服务器保持学习数据与偏好权威，客户端清缓存不调用删除材料或删除音频服务。配置变化只影响之后的新运行，不批量重评分/重合成；当前权限、Key 与供应商能力仍在每个新供应商调用阶段检查。

| 个人资料、语言与偏好 | UserExtension的profile_revision/study_revision/settings_revision；profile.updated、study_profile.updated、settings.updated，仅字段类别/数量，不含显示名、出生年份、性别说明或语言列表正文 |

| 安全能力目录 | 发布的模型/声音/格式/版本，不返回管理员私有配置 |
| 本机缓存/实例切换 | cache.cleared/evicted、account.scope.changed，仅计数、原因与平台 |

全部正常埋点和错误使用 [统一 Telemetry](../operations/observability.md)。上报失败也不在普通控制台输出 Key 或表单正文；测试与实际学习的模型调用用途分开，用量不重复累计。

## 7. 待决与后续

P1 下载/缓存管理增强需增加下载任务列表、暂停/继续、固定保留与存储配额联动；仍只管理客户端副本。P2 离线编辑/多设备冲突合并需要独立同步日志、授权有效性和冲突协议，未设计/验证前不放出“离线保存成功”功能。三语 UI、新语言插件、具体供应商默认值、精确生日/未成年人合规流程和任何公开资料/社交能力均不因基础字段存在自动成为首版承诺；如未来需要精确年龄门槛，必须另立身份/同意/保留契约，不能拿可选birth_year冒充。
