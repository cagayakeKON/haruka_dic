# 课本导入与单元学习

状态：2026-09-23，待实现设计。“课本”与其他文档的“教材”是同一业务类型 `textbook`。类型边界见 [三类材料契约](../contracts/material-types.md)，共用上传/书库/出处操作见 [材料模块](materials-reading.md)，TextbookManifest/Unit/Lesson/ContentNode/Edge关系见[解析数据结构](../contracts/material-structures.md#42-课本)；本模块独立于小说阅读和整卷考试。

课本正文、词表、例句以及普通课后题的题干/选项/已发布反馈统一支持[选区朗读与查询](ai-speech.md#21-全局选区交互)，查询结果再收藏；选文字不提交答案或切换题目。

普通课后题在作答前后均提供[直接收藏题目](vocabulary-practice.md#题目直接收藏)，仅保存当前有权可见字段；收藏不提交答案、不改变进度/得分、不调用模型。

DESIGN18：课本词表的每个独立单词旁提供小喇叭，正文、释义和普通习题沿用[长按句子分词浮层](ai-speech.md#21-全局选区交互)，可多选词查询和收藏完整结果；发音/选词不改变作答。

## 1. 范围、入口与权限

导入时选择课本，打开后进入单元目录/学习页。P0 覆盖 Unit/Lesson 及[八类内容展示](../contracts/learning-presentation.md#2-教材的八类内容展示)，包含课文、对话、词表、语法、例句译文、图片图注、通用表格和习题，按题型作答和逐题反馈；不把书籍字数百分比当学习完成度。P0 文件基础为 MD/EPUB，PDF/TXT/OCR 按产品优先级后续接入；单元完成度、讲练分屏仍为 P1。

内容读取使用 `client.material.read`，结构 AI 分析使用 `client.material.analyze`；练习、收藏、解释、TTS 分别检查实际动作权限。会读课文不代表可以生成或评分，缺 Key 不影响可靠原文和已有题的规则作答。

## 2. 流程、状态与异常

导入 → 保留格式结构 → 课本结构分析 → 生成单元学习页与质量报告 → 按可靠内容进入学习。确定性规则先识别原有标题/列表/表格/编号；AI 仅在明确请求时提出单元分组、内容角色及习题关联候选，所有引用由程序验证。

优先原书 Unit → Lesson 层级；无显式 Unit 时允许 Lesson/节直接位于书下，不强行补虚构课程。结构不明时放入课本自己的“待整理内容”，仍保留可读原文和顺序；不跳转小说阅读器，也不宣称完成课程结构分析。状态分别显示正文、单元结构和习题准备情况，不用整本单一 ready 掩盖失败单元。

内容分类、各自结构和交互以[展示契约](../contracts/learning-presentation.md)为唯一明细。Lesson 默认按原书教学次序组合内容，例如对话→词表→语法→例句→练习；角色筛选仅是导航，不按角色重新整理全书。答案页/附录保留来源用途，答案匹配到具体题目与版本后走练习投影，不直接嵌进题面；未知块保留可读原文与质量提示，未验证题型不生成假控件、不算完成。

用户进入单元 → 选择课文/词表/习题 → 学习或作答 → 查看逐题反馈 → 按需重做或收藏错题。词表条目可收藏到本人一个或多个[单词本](vocabulary-notebooks.md)，作为以后显式生成[AI习题](ai-exercises.md)的来源；课本不维护复习队列、SRS或第二套掌握度。只有冻结到具体词条/义项的有效分项证据才回流[自动掌握](../architecture/vocabulary-learning.md)，看过一页不标记掌握。练习完成依据服务端Attempt；回到单元恢复当前位置，不能重新提交上次答案。

可靠题面已抽取但缺原文答案时可保留作答入口，评分依据按 [公共作答](vocabulary-practice.md) 显示待准备/AI 参考；无依据、AI 失败或待复核不计作零分。是否在导入时预生成教材参考答案仍为 OPEN-05，不把本次拆分当作默认模型调用授权。残缺题干/选项和错配答案阻止相应题的可用状态，不阻止其他可靠课文学习。

## 3. 前端职责

`features/textbooks` 拥有 TextbookStudyController、单元目录、Lesson 页、词表与练习入口。紧凑布局按单元逐级导航，课文/词汇/练习入口定位对应内容；宽屏可常驻课程目录和当前内容区。它不复用 NovelReaderController 或 ExamSessionController；小型文本、选区、词条和题型控件可以共用。原文对照、图表适配及未知结构降级按展示契约执行，不以整页截图替代可选择的结构化文本。

按 [Flutter规范](../engineering/flutter.md) 处理触控/键鼠、软键盘、焦点和独立空间布局。输入答案属于普通练习会话，不放在小说进度里；切分区或重排不能新建 Attempt。词表用有界列表，复杂表格保留单元格关联；不为适应小屏把原书词义列拼接丢失对应关系。

P0 只恢复单元/内容位置及实际作答状态，讲练同时分屏与单元掌握度不提前启用。来源回跳优先打开对应 Lesson 与角色块并高亮，不打开全书长文本定位同名句子。

## 4. 后端职责

TextbookProcessingService负责Unit/Lesson、有序ContentNode、角色间ContentEdge和习题引用的校验与发布，TextbookStudyService提供课程结构和当前单元内容。TextbookManifest维护目录与各单元准备摘要，正文引用公共不可变SourceUnit/ContentBlock；对话轮次、词表行、表格格和答案关系保持专用身份，不能展平为小说段落。Exercise/Attempt仍由公共作答服务管理，可靠错误统一写入[服务端错题账本](ai-exercises.md#2-服务端错题账本)，课本不复制评分/错题实现。

版面关系优先于纯文本分句：表格不能拼成小说段落，图文/编号/共享题干不能按距离随意关联，答案附录不能混进课文。语言标注可复用基础能力，但只在所属正文/例句范围执行；单元、题目与空位 ID 不由分句器或模型生成。

AI 分析提交校验树无环、引用同材料/版本、内容范围有效、题干与答案绑定唯一且来源可信；低置信度候选不直接成为可靠答案。结构产物记录处理器/schema/分析版本；应用程序生成 ID。重解析发布新内容版本，练习会话保持冻结题目及出处，迟到分析不能改写既有作答。

按单元加载和重试已定义的 Job 阶段；没有可复用已提交阶段时明确重跑范围与模型用量并由用户重新选择，不能声称支持任意模型内部步骤恢复。AI 失败只影响对应候选/单元状态，通用任务与删除并发仍按公共契约执行。

## 5. 公共契约与依赖

依赖 [API](../contracts/api.md)、[出处](../contracts/content-locator.md)、[公共作答](vocabulary-practice.md)、[数据与任务](../architecture/data-jobs.md) 及 [AI/朗读](ai-speech.md)。课本题与考试题可以复用纯题型控件；即时反馈、提交事务和评分发布使用各自业务入口，不能通过课本入口逐题提交考试答案。

材料事件附受控类型/阶段；单元打开使用注册的 `textbook.lesson.opened`，正文位置保存复用阅读位置事件，练习成功沿用服务端 practice/attempt 事实，不多计一次“教材作答”。所有事件经统一遥测出口，按 [观测规范](../operations/observability.md) 注册白名单且不记录内容/答案。

## 6. 验收

| ID | 操作与通过标准 |
| --- | --- |
| TBK-001 | 带单元、词表、例句和练习的 MD/EPUB 保留结构/列关系和顺序；无 Unit 不虚构，有歧义显示待整理且原文可查 |
| TBK-002 | 同 Lesson 的题干、共享材料、空位和附录答案正确绑定；错配/残缺题受限，不影响其他可靠课文，无答案不伪装标准答案 |
| TBK-003 | 三端专用单元页可完成课文→词表→已有题→逐题反馈；切分区/窗口不重复作答，题型控件复用不串用考试事务 |
| TBK-004 | 位置与作答分开，来源回跳到正确 Lesson/版本；AI失败/重解析不改旧题和成绩，非法类型/跨用户引用拒绝 |

同时执行当期 MAT/READ/TYPE、PRA、[PRES展示验收](../contracts/learning-presentation.md#7-验收与分期)与适用 FLT 验收；当前尚未运行。

## 7. 待决与后续

OPEN-05 维护缺答案预生成策略；PDF/OCR/TXT、普通章节/块人工校正、单元完成度和讲练分屏按产品后续计划。课本内含小说摘录、笔记或练习册式章节只表示内容角色，不新增 article/notes/workbook/mixed 业务类型；若用户需要把内容作为整卷考试，必须走三类材料契约的显式重新处理。
