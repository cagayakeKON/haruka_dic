# 单词 CSV 导出与导入

状态：2026-09-22，未实现。本文维护单词CSV格式、转义、匹配/分批写入和往返验收的唯一契约；产品边界见 [产品总览](../product/overview.md)，界面入口见 [收藏与练习模块](../modules/vocabulary-practice.md)，授权机制见 [认证与隔离](../architecture/authentication.md)、[RBAC](../architecture/authorization.md)。

## 1. 功能边界

用户所需的备份与恢复仅通过单词 CSV 完成，界面称为「导出单词 CSV」「导入单词 CSV」。默认导出当前账号全部 kind=word 的收藏，也可明确选择当前筛选结果；列表分页不能限制导出数量。

恢复就是将CSV导入当前账号，预览后按重复策略新增或补全单词，并可恢复单词所属的多个词本名称关系，不清空资料库。不导出原书、图片、音频、短语/句子/摘录、练习、作答、调度历史、对话或账号设置；不存在整库ZIP、数据库还原或备份任务中心。掌握快照仅供查看，不凭CSV恢复可信学习证据。

CSV 包含单词笔记与上下文，属于用户自己的学习数据；不包含密码、会话、API Key 或其他用户数据。导入导出均无需模型 Key，也不自动调用模型。

导出要求client.vocabulary.csv.export+collection.read；预览/确认/分批导入要求client.vocabulary.csv.import+collection.create。比较、匹配或跳过既有记录还需collection.read，合并既有字段再需collection.update；写入权限不会隐含读权。无read时只允许用户显式选择“直接新增，不比较已有词表”，预览仅展示上传文件自身，既有重复数必须省略或标未检查，不能用0冒充检查结果。所有选定动作的权限在确认前和每批提交前校验，缺任一权限拒绝；后续撤权停止未提交批次，保留已成功数据。无Key不免除RBAC，管理员不能导出他人词表。

导出包含wordbooks列或按词本筛选还需client.vocabulary_notebook.read，预览及下载均重查。无此权限可由用户明确选择“仅单词内容”，省略wordbooks列且不查询/泄露本名、成员或计数；不能把不可读取伪装为空数组。该列缺省的v2文件仍有效，导入按无词本列处理。其他掌握快照属于本人词条结果，不因导出获得改写权限。

## 2. 文件与字段草案

文件名示例：Haruka-words-2026-09-22.csv。UTF-8 BOM、逗号分隔、首行为固定表头，使用 CSV 库处理引号、逗号和多行文本，不用字符串拼接或按物理行计数。表头及字段协议在阶段 1 固定，后续变更保留版本兼容。

| 字段 | Haruka 导出内容 | 导入规则 |
| --- | --- | --- |
| schema_version | 当前草案导出2；新增多本与自动掌握语义 | 明确兼容旧草案1，未带版本按外部词表映射；不支持的新版本拒绝自动解析 |
| csv_escape | 文本转义协议，建议 apostrophe-v1 | 仅在明确识别版本和协议时逆转义 |
| item_id | 原单词记录 ID | 仅用于当前账号的匹配提示，不授予更新/访问权限 |
| word | 单词表面形式 | 必填；去除无意义的首尾空白后不能为空 |
| lemma | 词典形 | 可空，不自动调用模型补全 |
| language | 目标语代码，如 en/ja | 缺失时由用户在预览中选择默认语言 |
| reading | 假名、IPA、拼音等 | 可空 |
| meaning | 释义 | 可空 |
| context | 收藏时上下文 | 可空，保留多行文本 |
| notes | 用户笔记 | 可空，保留多行文本 |
| tags | JSON 字符串数组 | 可空；外部词表可显式选择分隔符映射 |
| status | 当前只读mastery_state快照：new/learning/mastered/relearning | 只保存为未验证的来源状态快照，不写学习证据或当前mastery；旧v1的paused兼容规则见下文；未知值预览修正/标错 |
| mastery_policy_version | 该状态使用的判定策略版本，可空 | 仅与来源快照保存，不触发改策略、评分或调度重建 |
| study_control | active/suspended | 新条目按确认值初始化，缺失取active；合并既有条目不覆盖其当前控制/证据 |
| wordbooks | 本条目所属词本名称的JSON字符串数组，同一行目标语；按权限/所选导出范围可省略整列 | 当前用户同语种名称映射/创建并建立多对多关系；不是词本ID/owner，需所选动作权限；新条目空数组进入未分组，既有合并不会移出原词本 |
| source_title | 来源标题快照 | 可空，不用于自动匹配同名材料 |
| source_locator | 带协议版本、来源实例/资料库、材料版本及选区的定位 JSON | 可空；必须通过当前用户的材料归属和内容版本校验 |
| created_at | 带时区的来源创建时间；无来源时间时取本行创建时间 | 保存为来源时间；缺失使用本次导入创建时间，无效格式在预览中提示 |
| updated_at | 本行带时区的系统修改时间 | 保存为导入来源修改时间，不覆盖本行系统时间或绕过版本检查 |

原始表面词和词典形不因去重被自动改写；用于匹配的规范化值与展示值分开保存。往返保留单词内容/来源快照和已选择恢复的词本归属，不保证服务端主键、系统修改时间或内部审计记录相同，也不承诺掌握/调度结果相同。新条目一律从new开始，既有匹配条目保留真实练习证据；导入mastered只是外部声明，预览明确提示不恢复学习成绩。

v1兼容：原status的new/learning/mastered保留为非权威来源快照；paused可在预览中明确映射为study_control=suspended，不构造失败或掌握证据。没有wordbooks列时不改变既有条目归属，新建可由用户选择导入目标本或保持未分组。v2不得偷偷按v1的手动状态语义执行；不同协议的字段映射与警告在预览展示。

词本归属恢复是明确可选的列映射：需vocabulary_notebook.read/update和collection.read，新建缺失词本另需vocabulary_notebook.create。同一账号、同语种、规范化名称匹配，重复名称去重，外来ID/其他用户本不作为目标；名称解析结果提交时重验，冲突重新预览。缺权限必须显示原因，由用户明确取消该列映射或取得权限，不能静默丢本；无collection.read的直接新增模式不恢复现有词本关系。词本与本批成员写入同事务，跨批沿已创建的本人引用幂等恢复。

source_locator的字段、偏移单位、文本规范化与重绑校验统一引用 [出处协议](content-locator.md)，本篇只定义CSV中的序列化与导入处理。

### 时间字段与数据库映射

[数据库规范](../engineering/database.md) 统一要求created_at/updated_at表示本行数据库创建/实际更新时间。CSV输入中的同名字段是外部历史数据，校验后分别存入可空的source_created_at/source_updated_at（UTC带时区），不能赋给公共时间列、revision或授权事实。来源时间不作为服务器排序/版本冲突的可信时钟。

新建导入记录时，公共时间由数据库生成；有效来源时间单独保存。导出created_at优先取source_created_at，没有时取本行created_at，保留词条来源创建历史；导出updated_at取本行updated_at，因此系统修改时间不承诺CSV原样往返。source_updated_at保留供来源信息使用，不冒充本地修改时间，也不额外增加CSV列或改变schema_version。

跳过重复完全不更新时间；合并只补空来源时间且不改写已有非空历史值，真实业务/元数据发生变化时更新本行updated_at及revision，无变化重放不写。受控整库灾备保留原系统时间的规则不适用于用户CSV。

## 3. 导出与表格兼容

1. 后端从已验证会话确定 user_id，查询该用户单词及必要的来源文本快照。
2. 固定本次查询的数据视图，按稳定顺序流式生成 CSV；大量数据分批读取，不能仅导出当前页。
3. 提供经过授权的下载响应；Web 使用同源会话，原生端使用 Bearer 请求并交给系统保存。
4. 未完成的文件不显示为下载成功；下载失败允许重试，重试不改变单词数据。

全部单词仍导出为一个 CSV；较大词表由服务器流式解析和自动分批导入，用户无需手工拆分文件。建议每个写入批次最多 10,000 条，该值不限制全量导出的条数；实际文件字节上限须结合服务器容量设置并在入口显示。

CSV 的引号包裹不能单独防止表格公式执行。导出需对危险首字符进行可逆的文本转义，参考 [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)。建议协议如下：

- 对以单引号开头，或去除前导空白后以等号、加号、减号、@ 及对应全角形式开头，或以 Tab/CR/LF 开头的文本字段，加一个前导单引号，再交给 CSV 库编码。
- 明确标记 csv_escape=apostrophe-v1；Haruka 仅在识别该协议时移除由协议添加的一个单引号。普通外部 CSV 不盲目移除原始单引号。
- 用公式样本、日文、逗号、引号、换行、分号标签与 emoji 验证原样往返和目标表格软件的打开效果。

该转义方式需在实现时通过 Excel 等目标工具验证后定版；表格软件重新保存可能改变转义、日期和文本，不能承诺任意外部编辑仍无损。CSV 导入不执行公式或模板表达式。

## 4. 导入与重复处理

1. 选择 CSV；支持 Haruka 格式和只有 word 一列的外部表，允许列映射。
2. 流式校验编码、版本、字节数、逻辑记录数和字段长度；限制峰值内存，字节/字段上限在实施时确定。
3. 创建本人短期预览，展示上传数据有效/错误与样例；只有具备collection.read才查询并展示既有重复记录/条数，允许调整映射、语言和已授权策略。无read不使用CSV内item_id匹配既有记录，也不通过来源标题查旧词表。
4. 明确确认后才提交；有read时默认跳过重复，无read时必须显式选“直接新增、不比较”。合并还需update，混合所选动作缺权限整次确认拒绝。存在错误行时用户修正或明确排除后重新预览，不能静默丢行。
5. 在事务内重新检查当前导入权限、所有者、相关记录版本和重复条件；每个写入批次原子提交，并持久化游标/结果。确认与分批执行都需幂等，防止重试创建双份记录。
6. 返回新增、补全、跳过和排除的数量；大文件可在现有 Job 机制下继续处理。多批导入取消/失败时保留已成功批次，明确显示已完成与未处理条数，重试从已提交位置继续；未确认或过期预览需重新预览。

在确认页说明多批处理语义：单批失败回滚该批，不承诺整份大文件全部回滚；不删除已有单词或其他学习数据。预览批次、后台导入任务和进度均只对其所有者可见。

重复策略：

| 策略 | 行为 |
| --- | --- |
| 跳过（默认） | 已存在的匹配条目保持不变 |
| 合并 | 仅补空内容字段、合并标签和已授权的词本关系；保留非空释义/笔记/出处及当前学习控制/证据，不用来源status覆盖掌握 |
| 创建新条 | 明确创建独立收藏和新 ID |

具备collection.read且选择比较时，优先匹配本人确实存在的item_id并核验词/语言，外部条目按语言、规范化词/词典形与上下文/来源指纹提示重复；不能仅凭ID覆盖数据，不同出处不自动合并。无read的直接新增模式不执行这些查询，一律新业务ID；文件自身重复可提示，但不能混为数据库重复。幂等确认不依赖内容相似度。

跨账号/跨实例导入始终写入当前用户，以新 ID 保存。CSV 自报的 owner/user/library 字段不参与授权；只可能恢复当前用户确有权访问的有效 locator，否则保留 source_title/context，标记「CSV 导入」并禁用回跳。不按书名或裸 UUID 关联其他用户的材料。

## 5. 三端与验收

| 平台 | 导出 | 导入 |
| --- | --- | --- |
| Windows | 选择保存位置写入 CSV | 系统文件选择、预览和确认 |
| Web | 浏览器下载 CSV，必要时显示下载按钮 | 文件选择、上传与预览 |
| Android | 系统保存/分享流程，显示是否保存成功 | 系统文件选择、预览和确认 |

测试应覆盖：

- [ ] 当前用户 N 条单词导出 N 条逻辑记录，包括不在当前页的记录；B 用户条目不出现。
- [ ] 原样 CSV 在原账号按跳过重复导入，条数不增加；空账号导入保留定义的单词字段。
- [ ] v2多本名称归属往返，一词多本不复制词/学习进度；v1/外部词表映射、名称冲突和缺词本权限有明确结果；无notebook.read的导出明确省略词本列/筛选，不泄露归属；导入状态快照不制造mastered、due_at或作答记录，既有条目学习结果保持不变。
- [ ] 日/中/英、组合字符、emoji、多行笔记、标签及公式前缀可往返。
- [ ] 最小单列词表和列映射可用，无 Key 也能执行导入导出。
- [ ] 非法版本、错误行、超限文件、重复提交或并发修改有确定结果，不破坏已有数据。
- [ ] 伪造 item_id/source_locator/预览批次 ID 不能更新或读取其他用户内容。
- [ ] 导入/导出可分别授权，改按钮状态不能绕过接口；分批过程中撤权后停止后续处理，保留已提交数据并显示进度。
- [ ] 显式deny collection.read时不能通过重复预览/跳过/item_id探测旧词表；只能明确直接新增。缺update不得合并，混合动作缺权整次拒绝；批次间撤销read/update后停止相应未处理批次。
- [ ] 无材料时保留来源文本并禁用回跳，导入不触发模型合成或评分。
- [ ] 历史时间保存在来源字段，不能修改公共创建/更新时间或revision；新建/合并/跳过、无变化重放及再次导出遵循上述映射。

全部条目为待实施验收；这里定义的是单词字段往返，不承诺恢复完整学习资料。
