# 自动判断查询任务

日期：2026-09-25，阶段1内原型与文档小阶段 DESIGN14，基线5a42634。用户明确查询应由AI自动判断，不需要显示类型。范围为手机/电脑HTML原型和直接关联文档；不实现Flutter、模型或后端业务。

## 修改与边界

- 删除输入区的单词/句子/语法/习题选择器、需要切换类型才能发送图片的限制，以及消息中的任务标签。用户直接输入文字、添加图片或纯图发送；示例仅显示内容，点击仍追加草稿，不自动发送或预设类型。
- 语言范围不变：单词/短语、句段翻译、语法和语言习题；图片仅处理语言句段翻译/语法或习题批改。AI根据实际内容与上下文判断，必要时用自然语言询问补充信息，不以类型选择器转交判断工作。
- 查询结果仍采用对应的学习卡片，并按真实内容类型收藏。原型只自动匹配四个内置文字样例；含图消息明确未识别，不输出伪造的分类、卡片或收藏入口；非语言/未匹配内容不返回通用回答。
- 正式API不要求或接受客户端query_task，任务推断作为服务端轮次结果保存；幂等摘要使用实际输入、附件与模型配置，重放读取原结果，不重新分类或重复调用。相关产品、查询、Agent、数据及API规格已同步，正式业务仍待实现。
