# 语言查询与学习卡片

状态：2026-09-25，DESIGN14按用户最新要求由AI自动判断语言任务，输入区不显示或要求选择类型，P0 已确认、正式业务待实现。支持文字、图片与图文混合查询，Web粘贴图片、Android相册及直接拍照均为已确认入口。HTML原型只提供本机图片预览、内置单词/句子/语法/习题示例与内存收藏，不上传图片或调用模型；Android系统相机与权限仍需正式客户端验收。卡片结构由 [AI 与朗读](ai-speech.md) 维护，运行由 [Agent 运行层](../architecture/agent-runtime.md) 负责。

## 1. 入口与范围

“查询”是手机与电脑的独立语言学习入口，不要求先导入材料。只接受单词/短语查询、句子或文章翻译与语言解析、语法问题、语言习题批改；不提供自由提问、百科问答、通用看图问答或非语言任务。图片只用于识别语言句段后翻译/解析语法，或识别题目与作答后批改。材料仍只有小说、课本、试卷三类，查询不是第四种材料。

查询是具体语言学习功能，不提供独立Agent聊天、会话列表或通用闲聊。页面包含统一图文输入、历史查询及分类型学习结果，不显示任务类型选项。用户直接输入或添加图片，AI根据实际内容和上下文自动判断语言任务；判断不明确时以自然语言询问必要信息，不要求用户理解或选择内部类型。手机优先保证输入、附件、发送和收藏触控面积；电脑限制内容行宽；输入区与结果按文档流排列，不悬浮遮挡卡片，发送后定位新结果，卡片的“再查一个”返回输入。Enter 换行，Ctrl/Cmd+Enter 发送；中文输入法组合期间不提交。文字与有效图片皆空时禁止发送；仅有图片也可直接提交，不强迫填写占位文字或先选类型；AI识别后仅在句段翻译、语法解析和语言习题批改范围内处理。文字和图片上限由公开配置统一发布。发送前保留草稿，失败/结果未知时可恢复原轮次，不自动重发。

首次进入时先显示输入与附件/发送操作，示例问题放在输入区下方，只显示可直接使用的示例内容，不列类型标签；示例不占据首屏主要操作位置。点击示例仅追加到草稿，不直接发送，不覆盖已有文字或图片；超过文字上限时保留草稿并说明如何调整。点击示例不预设类型，保留草稿和附件；有结果后按查询与结果、后续输入的顺序显示。DESIGN14已在HTML原型验证直接输入与自动匹配示例的顺序，正式客户端仍待实现。

查询沿用 AgentThread/Message/AiRun，线程标记 `mode=query`；阅读解释等业务功能的内部上下文标记 `mode=contextual`，不对应聊天界面。语言学习输入允许无材料引用；用户显式附带的收藏/材料另验来源权限。历史每轮保留当时的解释语言及可选目标语言；任务类型不代替目标语，目标语不明时按收藏规则确认。任务由服务端AI推断并校验，客户端不提交query_task；服务端检查实际输入和输出是否属于语言学习；超范围或无法判断时仅给范围/补充说明，不输出通用回答或可收藏卡片。外语输入本身不代表语言学习：翻译或分析一个百科句子可以受理，要求回答其百科知识则不能以外语绕过限制。HTML仅精确匹配内置样例；其余输入不生成卡片，这不是正式语义识别已实现。

### 1.1 图片输入与移动端操作

| 平台 | 已确认入口与行为 |
| --- | --- |
| Web | 输入区“图片”选择本机文件；输入区获得焦点后，通过用户的粘贴动作读取剪贴板图片。混合粘贴保留文本与图片，纯文字粘贴维持编辑行为；不后台监听剪贴板、不自动读取HTML中的外链图片 |
| Android | 输入区同时提供“相册”和“拍照”。相册选择本人选中的图片；拍照直接调用系统相机/平台适配器，拍摄确认后回到查询草稿；无需先保存到相册再手动寻找 |
| Windows原生 | 提供本机图片选择；与Web共用图文消息和附件状态。系统剪贴板能力按适配验证，不以HTML粘贴测试宣称原生已支持 |

图片选择、粘贴或拍摄后先显示缩略图，发送前可放大预览或逐张移除。预览关闭回到触发点，移除后保持文字草稿；横向图片条不挤出发送按钮，附件动作至少44px、并列动作间隔8px。返回取消选择/拍摄不清空已有文字或图片，也不发送消息。相机权限只在用户点击拍照且平台需要时请求；拒绝/永久拒绝/相机不可用时给出原因，保留草稿并允许改用相册，不能循环弹权限或自动上传。

状态区分本地准备、待发送、上传中、上传失败和已随消息提交。某张失败需明确重试或移除，不静默漏图后发送；上传/校验未完成时禁止提交，发送后图片与当轮文字固定关联，不能被后续草稿替换。图片不经材料导入，不新增材料类型，也不自动创建单词或启动拍照词表任务。

正式图片策略由配置发布允许格式、每轮数量、单张字节/像素及总请求限制；前端提示不替代服务端检查。当前HTML原型以PNG/JPEG/WebP、每轮最多4张、单张10MB和2400万像素演示交互，这些数值是原型限制，不代表正式部署已验收。格式、损坏文件、超限或解码失败就地说明，已有草稿保留。

### 1.2 就地选区查询

非试卷学习文字统一通过[全局选区交互](ai-speech.md#21-全局选区交互)打开朗读/查询工具条；查询结果在当前位置的面板展示，不跳转或打开聊天。已提交的AI解释、中文说明和例句也可继续选区查询。独立查询页沿用统一输入；两种来源共用语言任务范围、四类卡片与收藏协议。服务端按实际来源映射explain或agent.use及来源read权限，不因为统一按钮名称而合并授权。材料选区先复用已有解释，只有明确新查询才生成；结果全部持久保存，收藏只增加组织关系。

## 2. 学习结果与收藏

1. 用户主动发送后，服务检查 agent.use、本人模型配置和调用上限，创建有幂等键的轮次。包含图片时必须使用本人已配置且支持图像输入的视觉模型，文字与有序图片进入同一轮上下文；无视觉能力/Key或超限时保留草稿并提示配置，不丢图降级为纯文字回答、不调用他人Key。无 Key 仍能浏览本人已保存消息和卡片，不生成假回答。
2. 流式文字展示处理中/停止状态。只有完整通过类型、来源和业务校验且已持久提交的卡片可以收藏。WordCard、SentenceCard、GrammarCard、ExerciseCard 按各自类型呈现；结果直接对应单词/短语、句子、语法或习题，不存在通用AnswerCard/answer类型。语言任务之外的结果、未识别图片和失败说明没有收藏按钮。
3. 点击收藏打开归类弹窗，可选零个或多个本人同语言单词本；未选择进入全部收藏/未分组。语言不明时先由用户确认卡片目标语言，不能无提示塞进当前词本。正文、例句、解释与来源组成版本化快照，不能只存标题。
4. 提交 `card_id + card_revision + notebook_ids`；卡片无明确目标语或为混合语言时，另提交用户显式确认的 `confirmed_target_language`。服务重取本人已提交卡片：已有明确目标语不得被此字段覆盖；无明确目标语时验证受支持语言值、用户确认与所选词本语种一致，再保存收藏的语言。语言确认不改写历史卡片，解释语言不自动充当目标语。不接受客户端自报卡片正文或 owner。幂等请求摘要包含确认语言和归本选择，同键异载荷冲突；本人同一卡片版本只建一条收藏，已有收藏的归类/语言变更走独立带版本更新，不能借重复收藏静默覆盖。界面在提交成功后才显示“已收藏”。归类失败保留选择并报告原因。
5. 收藏结果在单词本条目列表可搜索和查看；详情为弹窗。修改归类不复制内容，不刷新“加入日期”，删除单词本保留收藏。单词进入每日单词；语法、句子、习题保留各自类型。习题收藏保存题目、用户作答、建议订正、依据及不确定性，查询批改仅供学习参考，不建立PracticeSession/Attempt、不更新掌握或自动错题账本；正式作答与有效评分仍走习题/考试流程。

用户输入与模型生成例句不伪造书籍、段落或网页出处。已有材料引用继续保留合法 locator；没有来源时显示查询来源。语言查询不获得联网搜索、访问外部账号或执行任意工具的授权，首版不据此增加浏览器、任意 URL 抓取或管理工具。

图片文字与画面同样属于不可信用户内容，不能改变系统指令、权限或工具范围。答案可说明“图片1/图片2”的依据与不确定性，不能伪造材料locator。收藏保存对应类型的完整学习卡片和查询来源信息，不自动把输入图片复制进单词本；查看来源图片仍需会话读取权限，来源删除/失权时说明不可用并保留已收藏学习载荷。原型含图消息只显示明确的未分析状态，不把文本内置答案冒充看图结果。

## 3. 权限、持久化与异常

历史/卡片使用 agent.read；生成使用 agent.use；收藏使用 collection.create 和卡片读取权限，归本另验 vocabulary_notebook.read/update；读取收藏使用 collection.read。任一来源或工具操作逐次检查当前权限；查询批改不能绕过考试题面/答案隔离。所有会话、卡片和收藏按当前用户隔离，退出后停止订阅、清理私有内存，丢弃旧账号迟到响应。

模型不可用、输出校验失败、取消和网络中断分别显示真实状态；部分文字不作为成功卡片。恢复先读取原 run 快照，不能为恢复卡片再次调用供应商。成功结果自动持久保存，收藏只增加用户组织关系。日志沿用事件白名单，不记录问题、回复、卡片正文或 Key。

### 3.1 私有图片附件

图片使用专属query_image用途的临时上传意图，归属当前用户和查询会话；复用[不可变对象发布](../architecture/data-jobs.md)，不能将任意FileObject、其他会话附件、外链URL或客户端owner直接当作查询图片。创建意图/完成校验/发送轮次及每次供应商调用前分别重查权限、归属、会话状态与资产版本。具体接口和请求引用由[API契约](../contracts/api.md)维护。

服务端核验真实格式、体积和像素，受限解码、规范方向、去除EXIF/定位等元数据并重编码为受控静态图后才发布不可变资产；客户端解码成功不代表服务端安全校验通过。模型输入由后端从已发布私有资产读取，不让供应商自行抓取用户任意URL。历史图片读取每次检查agent.read和本人会话，使用private/no-store，资源签名、图片载荷、EXIF、文件名与本机路径不进入日志。模型用量中的input_images按[统计契约](../contracts/model-usage.md)记录，不换算虚构文本Token。

发送在会话事务中验证全部附件可用并冻结有序引用；幂等摘要含用户文字、附件身份/版本/顺序及模型配置，不包含尚未推断的任务；推断结果随原轮次保存，重放复用原结果，不重新判断或发起调用。同键异文/异图返回冲突。重复完成/发送不能重复发布附件或新轮次。绑定后的附件不能通过“移除草稿图片”接口改写历史；已有图片不可用时明确阻止新视觉调用，不能静默跳过。

未绑定临时附件可由本人移除或在配置期限后回收；消息/运行有效引用期间不可因普通TTL删除。删除会话后封存并按引用受控GC，迟到上传或模型结果不能复活已删会话。退出/切换账号清理该账号的草稿、缩略图与本机临时文件，撤销临时URL；拍照/选择器/上传迟到回调按账号与请求代次丢弃。进程恢复只接纳仍有权且属于当前账号的草稿，不能重复拍摄/上传或自动发送。正式流程仍遵循认证、共同父行锁、无物理外键和日志约束。
