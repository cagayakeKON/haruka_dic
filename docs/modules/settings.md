# 个人设置、模型凭据与客户端缓存

状态：Draft v0.1，2026-09-22，尚未实现。本文负责设置表单、配置生效和缓存操作；注册/登录/改密/设备会话以 [账号流程](accounts.md) 为准，身份/权限/离线限制以 [认证与隔离](../architecture/authentication.md)、[RBAC](../architecture/authorization.md) 为准。全部 API 为未来契约，见 [API 契约](../contracts/api.md)。

## 1. 设置页与权限

设置入口按可用子功能展示账号资料、安全、服务连接、模型与 Key、语言、阅读、朗读、单词数据和本机缓存。没有 profile 权限时不返回整份个人配置，仍保留经过身份验证的本人安全/退出入口；权限快照不得因设置页不可见就无法更新。

登录和缓存初始化只依赖当前受众的 me/access 返回的最小本人主体标识、instance_id、audience、session_ref 与权限版本，具体信封以 API/账号协议为准，不把 users/me 或 settings 的 profile.read 当所有账号启动前置条件。有 profile.read 才并行读取个人资料/偏好；没有时使用安全的界面默认值，仍可进入有权页面或受控空状态。最小主体标识用于绑定 AccountScope，不返回完整个人资料或任何会话凭据。

| 子功能 | 权限/范围 | 持久化与边界 |
| --- | --- | --- |
| 显示名/学习偏好 | client.profile.read/update | 服务端 User/StudyProfile/Settings，版本控制；不能修改邮箱/角色/状态 |
| 改密、本人会话、退出 | 账号流程的本人安全操作 | 不依赖学习菜单；具体重验/撤销规则不在本文复制 |
| Key 掩码/状态 | client.credential.read | 当前用户的 ProviderCredential 安全 DTO；永不返回明文 |
| 新增/轮换/删除 Key | client.credential.manage，必要的近期重验 | 后端加密，明文只在受控输入和本次服务调用内使用 |
| 测试 Key/模型能力 | client.credential.test | 单独显式操作，可能收费；manage 不等于可付费测试 |
| 模型/声音选择 | profile.update；使用还需该业务权限 | 绑定本人 credential_id 与能力目录条目，不能由设置取得额外角色权限 |
| 单词 CSV | vocabulary.csv.export/import | 跳转同一 CSV 功能，不导出设置/Key/音频 |
| 本机清理与容量 | 当前账号本机操作，不授予服务器删除能力 | 无网络也可清理；管理后台不离线缓存业务数据 |

`client.credential.read/test` 为本轮细分草案，所有代码以 [权限目录](../contracts/permissions.md) 为中央登记。已保存配置是否允许使用在每次调用时重新判断，管理员禁用模型/降低额度不会只改变 UI。

## 2. 服务地址与服务实例

Windows/Android 在登录前可配置 Haruka 服务地址，登录后更换地址视为切换服务实例。只接受经过校验的 HTTPS base URL，拒绝用户名/密码、query、fragment 和不允许的协议；开发 HTTP 例外只存在明确的开发配置，不由发布版“忽略证书错误”开关解决。服务地址不是供应商 base_url，不能提交给后端变成任意 HTTP 代理。

正常流程：输入地址 → 独立无凭据连接探测 → 展示服务身份/版本/兼容性 → 确认使用 → 登录。建议公共 `GET /api/v1/meta` 返回 instance_id、服务名、版本/最低客户端版本和非敏感能力标识；实际结构由 API 契约登记。探测不发送当前账号 Cookie/Bearer/个人 Key，不因相同邮箱假设两实例共享账号。

Web 推荐固定同源部署，显示当前服务地址和连接状态；不在运行中的 Web 应用里任意更改 API origin 并转发 Cookie。使用其他部署通过打开该部署的独立地址完成并重新登录，不能绕过 CORS/CSRF 或将 MyHome 会话当 Haruka 会话。

登录后的切换先提示“将退出当前实例并清理本机该账号缓存”，停止新操作，尽力撤销原会话，随后本地清理并增加账号代次；远端撤销失败按账号流程明确提示，不阻止本机清理。连接新实例失败保持未登录状态，不恢复旧明文凭据或把旧请求自动改发新地址。缓存分区绑定经确认的 instance_id 与规范化地址，不仅按邮箱命名。

## 3. 个人 Key 的创建、轮换、测试与删除

### 保存

1. 选择 provider；首版允许配置的入口为 OpenRouter 与 Gemini 直连，具体默认值仍待确认。界面说明文本/视觉/TTS 可能需要不同能力，Key 本身不代表所有模型都可用。
2. 输入 Key 时默认掩码，可临时显示/粘贴；不回显旧 Key、不自动填入浏览器持久表单/普通偏好，不写错误日志、分析事件或崩溃上下文，应用不主动复制到剪贴板。UI 完成/离开即释放其受控输入状态，不声称能保证运行时字符串内存物理擦除或清除操作系统已有的剪贴板历史。
3. 点击“保存”经 HTTPS 提交到本人 credential 服务，校验允许 provider/长度与权限，不调用模型。保存和测试是两个操作；保存只证明已加密持久化，状态显示 untested，而不是“连接成功”。
4. 后端用部署 Secret 中独立主密钥封装加密，保存 owner、provider、密文、credential_version、encryption_key_version、revision、状态与掩码。credential_version 是用户供应商 Key 的更换/撤销代次；encryption_key_version 仅引用部署加密 Keyring 的主密钥版本；row revision 独立用于并发更新。密文和明文都不作为 API 响应、Job 参数或日志属性，任务只保存本人 credential_id 与必要的安全版本引用。
5. 返回掩码/标识和 revision，客户端清除 Key 输入。默认模型配置可绑定该 credential_id；另一账号伪造 ID 时不返回其存在或掩码。

### 能力测试

测试按钮要求 credential.test；用户选择文本/视觉/TTS 中要验证的一项，显示会发送的固定最小样本、调用次数和可能计费。不得点击一个通用“检测”就悄悄调用三种能力。测试通过当前用户的同一模型工厂/音频适配器和预算执行，有单独 operation_id；不使用用户私有整章材料作探测输入。

结果包含本次 provider/model/capability、配置版本、tested_at、成功/失败类别和安全用量。失败区分 Key 拒绝、模型不可用、能力不符、额度不足、限流、网络故障、格式错误；不返回供应商请求完整转储。网络失败不自动将凭据永久标 invalid；模型/声音失败也不代表同一个 Key 的其他能力都无效。测试结果是某时刻该组合可用，不保证未来请求成功。

### 轮换与删除

更新/撤销供应商 Key 使用 expected_revision，成功推进 credential_version，清理本账号旧解密客户端/配置缓存；新密文写入当前有效 encryption_key_version。新付费阶段只读取当前有效 credential_version，不拿它查部署主密钥。已经开始的外部调用不能承诺撤回，在途返回按 [数据与任务](../architecture/data-jobs.md) 的最低限度保存/清理处理。普通设置更改不批量重新合成音频或重评分。

删除前显示受影响的文本/视觉/TTS 绑定及尚未完成任务数；确认后将凭据不可用并删除密文或进入受控密钥删除策略，解绑当前选择。等待执行的付费任务进入可恢复的 blocked/Key-required 状态；恢复需要用户配置新凭据并显式继续，不自动借用另一个 Key。已经保存的解释、题目、音频、答卷保留，按各自权限可读；删 Key 不等于删除这些成果。

并发轮换/删除冲突返回当前 revision 和安全状态，保留用户本次输入直到其选择重试/放弃，不能在响应中重发旧明文。主密钥运维轮换重加密密文并更新 encryption_key_version，不改变供应商秘密含义或 credential_version，也不触发模型测试/重新合成；该迁移与用户更换 Key 使用独立版本比较和并发保护。主密钥不能作为用户设置页字段，运维/归档密钥保留规则见 [配置与运行](../operations/configuration.md)。

## 4. 模型、语言与阅读/朗读偏好

| 配置组 | 字段/交互 | 生效逻辑 |
| --- | --- | --- |
| 文本 | provider、credential_id、model_id、解释语言/详细程度 | 下一个新 run 使用新 settings_revision；活动 run 保持其冻结模型参数，凭据有效性仍逐付费步骤检查 |
| 视觉 | provider/模型/credential、目标语和释义语言默认 | 用于拍照/获准 OCR 任务；不因能传图片就声称可可靠解析整卷 |
| TTS | provider/模型/credential、按语言声音、实际支持的合成参数 | 新请求使用新合成键；已缓存旧声音仍标识其配置，不假装已切换 |
| 语言 | P0 界面 zh-Hans；母语、target_languages、active_target_language | 激活语言须属于已选目标语；切换刷新诊断/练习范围，不改旧记录语言、不删除历史 |
| 时区 | IANA 时区标识，初始取设备建议并允许用户确认修改 | 用于日期展示与诊断窗口；后端校验，历史仍存 UTC，不改变考试截止或会话期限 |
| 阅读 | 字体类别、字号、行距、浅/深/sepia | 即时预览、保存成功后跨端使用；字体不可用使用可预期回退，不改原文锚点 |
| 朗读 | 播放倍速 0.7–1.5、默认声音 | 倍速是播放偏好，改变不触发新合成；合成语速另列且仅能力支持时可选 |
| 解释 | 简短/标准/极客；母语或目标语说明 | 下一次解释/缓存键生效，已有解释保持原版，可显式重新生成 |

模型/声音目录从后端允许清单读取，显示 capability、是否已验证、下线/不可用信息；“管理端允许”与“本人 Key 实测可用”分开。P0 不开放用户任填供应商 URL、Prompt 代码或任意 HTTP Header；模型 ID 可以从已允许目录中选择，不让模型回答修改配置。具体默认模型和声音待技术验证，不把文档举例当永久可用项。

界面语言/母语/目标语是三个字段。P0 界面只承诺中文；母语和英/日学习的默认组合可用，其他语种能力按版本/插件开关显示，不承诺切一个 locale 就得到同等质量。移除目标语只改变偏好和默认筛选，不删除该语种单词、成绩或对话；仍能在历史筛选查看有权数据。

所有服务器偏好保存带 expected_revision。UI 可临时预览字体/颜色/倍速，但明确“未保存/保存失败”；刷新以服务器值为准，冲突展示双方变化并选择重试，不一方静默覆盖。切设置不会重复执行页面初始化的付费任务；权限/配额不足保存或使用时有明确业务错误。

## 5. 缓存职责与离线读取

服务端保存业务真相，客户端只缓存可重建内容、授权音频和有界遥测。P0 不建立收藏/笔记/练习/设置的完整离线写队列。考试的短时未同步草稿是 [考试专题](exams.md) 的单独例外，不借缓存文档扩大离线考试保证。

| 缓存 | 分区/有效性 | 清理影响 |
| --- | --- | --- |
| 目录/章节 | instance + user + audience + material_revision + content_id；当前读权限和离线租期 | 仅删除本机副本，下次在线按权重取 |
| 音频 | 同上用户分区 + asset/合成键/真实格式，下载校验完成才标可离线 | 不删除服务端音频，不重新计费；可重新下载已授权对象 |
| 权限/配置快照 | 从 access 最小主体绑定实例/账号/audience/session_ref、user_authz_version/policy_revision 与服务端期限；profile/settings另按权限读取 | 非当前版本不可为在线授权；管理端不离线使用；缺profile权限不阻断身份初始化 |
| 当前页面临时输入 | 账号代次 + 业务版本，只供当前工作流恢复 | 退出/换账号销毁；未提交不能宣称已保存 |
| 遥测补传 | 实例/用户/audience/账号代次、事件白名单/TTL/容量 | 队列清理计数，不挪用为答案/笔记正文存储 |

租约由成功在线鉴权后签发/更新的服务器期限决定，推荐最长 24 小时且部署可缩短，严格依据 RBAC/账号会话的更短有效期限。客户端记录服务器时间锚点与单调计时；本地时钟回拨不能延长租约。进程重启后无法可信确定剩余期限时要求联网，不凭修改设备时间续租。不能声称客户端租约是对已拿到文件的强 DRM；它约束官方应用的授权显示。

网络不可达才可在有效租期内读已有章节/音频；一旦服务器明确返回会话撤销/权限拒绝，不能切“离线”绕过该结果。恢复网络先验证会话和权限版本，再继续同步/下载；被删除或失权内容清缓存、停止播放器。首次注册/登录、新章节下载、修改收藏/设置、生成/评分及管理操作都要求在线。

缓存索引推荐 Drift，Windows/Android 使用平台 SQLite，Web 使用经过支持验证的 WASM 存储路径。Drift 官方提供 [Web/WASM 接入方案](https://drift.simonbinder.eu/platforms/web/)，但浏览器持久化、配额和多标签行为仍需目标浏览器验证；Web 隐私模式、配额回收或用户清站点数据会丢本机缓存，不能因此丢服务器学习记录。

本机缓存数据不等于秘密凭据仓库。刷新材料进操作系统安全存储或 HttpOnly Cookie；Key 不进 Drift。用户可以获得自己的本机数据，本项目不承诺抵御已经控制设备的攻击者；应用仍禁止跨账号复用文件/索引和日志泄漏。

## 6. 下载、清理、账号切换与并发

P0 支持已读章节/已生成音频的基础缓存以及“清除此账号本机缓存”。缓存容量有上限，按最近使用淘汰可重建文件；正在播放/读取的文件加短期引用保护，清理时先停相关消费或延后删除，不能删到另一个服务实例/账号目录。P1 才增加整章选择下载、队列管理、固定保留、按材料清理和更细容量面板。

下载先写临时对象，核对长度/摘要后原子登记 ready；磁盘满、网络中断或进程结束留下的临时文件可清理，不能将截断音频当作成功。并发下载同一资产复用受控任务；切账号时取消客户端下载，旧回调经 account_generation 拒绝写入新分区。服务端独立生成 Job 保持原用户归属，普通退出不会转给新用户或自动取消。

清理流程：展示范围/容量 → 用户确认 → 停止关联播放/下载 → 清理本机索引和私有文件 → 返回已清理/失败数量。清理失败保留待清理标记并重试，不能删除任意服务器资料。只清缓存不退出；退出/换账号则清除该账号凭据、缓存、草稿、队列、订阅及临时文件，顺序和远端撤销以 [账号流程](accounts.md) 为准。

切账号/受众使用全局 AccountScope 的递增 generation。所有请求、Stream、下载、播放器、Repository 和 Riverpod 状态带创建时 generation；响应应用前检查相符，否则丢弃。Web 同源 client/admin 可有各自会话，但缓存/队列/授权仍按 audience 分区；管理页面关闭不应清掉另一个仍有效用户端会话的 Cookie，退出当前受众也不错误宣称两端已全退。

“退出全部设备”属于服务器会话撤销，不能保证远程设备上的用户副本立刻物理删除；在线设备在下一授权边界清理，离线遵守租期上限。Haruka 不提供整库 ZIP 或缓存文件恢复按钮，单词迁移仍只有 [CSV](../contracts/vocabulary-csv.md)。

## 7. API、事件与三端映射

| 操作 / 待实现 API | 权限/规则 | 数据和事件 |
| --- | --- | --- |
| `GET /api/v1/meta` | 安全公共元信息，无用户/权限目录/秘密 | instance 与兼容信息；connection.probed 仅状态/延迟，不含完整自定义地址 |
| `GET/PATCH /api/v1/users/me` | profile.read/update | 显示名等白名单；profile.updated，不记字段正文 |
| `GET/PATCH /api/v1/settings` | profile.read/update | Settings revision 与能力绑定；settings.updated，仅变更字段类别 |
| `GET/POST /api/v1/provider-credentials`、`PATCH/DELETE /provider-credentials/{id}` | credential.read/manage | 密文、版本与掩码 DTO；credential.created/rotated/deleted |
| `POST /api/v1/provider-credentials/{id}/test` | credential.test、明确测试能力/预算 | AiRun/ExternalCall 安全结果；credential.test.completed/failed |
| `GET /api/v1/model-capabilities` | 当前 client 登录基础能力，仅发布的安全目录 | 模型/声音/格式/能力与版本；不返回管理员私有配置或真实 Key |
| 本机缓存清理/服务切换 | 本机动作，不调用服务器删除材料接口 | cache.cleared/evicted、account.scope.changed；只计数/原因/平台 |

模型目录查询/凭据测试路径需登记在 API 中央契约，不能与管理端 model-catalog CRUD 共用无字段裁剪接口。所有前端日志和正常埋点使用统一 Telemetry；即使上传队列故障，也不在普通控制台输出 Key/表单内容。密钥测试与实际学习付费分别标用途，统计不重复计费。

| 平台 | 设置与缓存专项验收 |
| --- | --- |
| Windows | 安全存储可用/失败、文件锁/磁盘满、应用重启；更换实例不会复用原会话或旧路径 |
| Web | 同源 Cookie/CSRF、多标签 AccountScope 协调、缓存被回收/隐私模式；无 localStorage 长期 Token |
| Android | 安全存储、进程重建、系统存储压力、后台下载取消；账号切换不会播放旧音频 |

## 8. 后续边界与验收
