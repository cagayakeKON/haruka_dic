# 「晴空频率」双端原型审查

日期：2026-09-24。阶段1的独立设计原型小阶段 DESIGN2。范围为[原型页面与清单](../../../prototype/README.md)及受影响的产品、导航和交付文档；不计入 Flutter/Python 的 B1/B2 工程完成度。视觉依据是[产品设计语言](../../product/design-language.md)。

## 交付行为

原型重新建立手机与电脑两个入口，分别维护页面结构、导航、样式和交互脚本，仅共用虚构数据与基础图标。手机使用底部主导航与层级页面，电脑使用侧栏工作台、分栏阅读及独立管理端示例。两端都覆盖材料、三种专属学习场景、词本、显式选源习题、错题、Agent、消息、任务、账号和设置；电脑另有管理端页面。逐页范围及演示边界以[原型清单](../../../prototype/README.md)为准。

交互均为本机内存演示。导入不读取文件，登录不鉴权，模型、OCR、TTS、Agent 与保存不调用业务服务。考试必须按准备、开考、交卷、复盘的顺序进入；交卷后不能回到作答页修改答案。

## 独立审查与修订

作者为 root；独立审查由 prototype_review 执行。第1轮发现以下直接影响本阶段的缺陷，作者集中修订；第2轮对考试状态边界做定点复核，确认该缺陷关闭。

| 发现 | 修订与证据 |
| --- | --- |
| 交卷后可经 `#examRun` 重新进入并改答案 | 手机和电脑路由都在已交卷时转向结果页；浏览器实际完成开考、作答、交卷后验证返回作答深链被拦截 |
| 注册缺少确认密码与受理、登录分离 | 两端补确认密码校验、受理状态和独立登录入口；首次设置可跳过 |
| 管理端没有自身账号安全/退出与受众切换 | 桌面管理侧栏增加安全页、退出动作；切换用户端后需重新进入登录示例 |
| 自评水平、阅读字体/主题显示为选项但不产生实际效果 | 水平进入本地状态；阅读偏好作用于小说正文，并实际检查显示样式 |
| AI 习题只按来源大类选择，未锁定具体范围 | 补具体词本、全部单词、教材单元和错题范围，预览数量及摘要随选择更新；改动来源或题型会撤销旧预览 |
| 路线图仍称原型未迁移；文档存在空白行差异 | 同步当前原型状态，修正差异，并执行差异空白检查 |

第2轮没有宣称对全部页面再次独立审查；其余修订由作者做浏览器定点验证和页面覆盖检查。

## 实际检查与限制

- `node --check` 检查 `data.js`、`core.js`、`phone.js`、`desktop.js` 通过；`git diff --check` 通过。
- 浏览器在 390×844 检查 35 个手机用户入口，在 1024×768 检查 33 个电脑学习入口和 9 个电脑管理入口；各页有标题，无页面横向溢出，桌面端无控制台错误。另抽查 320px 手机、1024px 电脑及关键视觉页面。
- 浏览器操作验证考试交卷边界、词本选源与预览、英语目标语言示例、阅读偏好、注册状态及管理端切换等关键流程。
- 当前检查只证明 HTML 原型可浏览和本地交互符合展示意图。未验证真实认证、上传、持久化、模型调用、服务端考试规则、Flutter 原生三端或无障碍完整验收。
