# 电脑端排版与交互重构

日期：2026-09-24。阶段1内的独立原型小阶段 DESIGN5，基线 d9ef0ea。用户要求电脑端对齐手机设计语言，以移动优先原则优化电脑操作、排版并删除无意义说明。本次仅修改电脑 HTML/CSS/JavaScript 原型与相关文档；手机原型、共享样本、Flutter/Python、依赖及业务契约未改。

## 交付内容

- 沿用手机的浅色表面、晴空蓝、芽黄绿、书封色块和圆角，统一材料库/单词本/练习/我的四个核心目的地。以单列为基础，在宽窗口展开侧栏、设置分类、阅读解释与目录；移除强制 760px 最小宽度。
- 材料首页直接呈现类型筛选、搜索与书目，取消宣传横幅；详情突出书封、内容、状态和主操作。词本改为书脊卡片并显示实际示例词条数。
- 导入采用三步表单；练习首页区分生成、已有习题、错题与诊断，生成独立为两步选源/设置/预览/确认。教材的内容与课后题对应当前单元；练习页聚焦题干、选项和反馈。
- 阅读字号、行距、字体和主题在弹窗就地调整；宽屏选词与右栏联动，窄窗口使用解释弹窗。Agent 的消息区域独立滚动、输入区常驻，发送后显示最新回复并保留输入焦点。
- 添加搜索快捷键、对话发送快捷键、可见焦点、弹窗焦点循环/Escape/触发点恢复和背景隔离。历史记录保存资源身份，已删除词本回退列表；尺寸变化保留选择与输入，考试离开确认后可以续答。
- 删除重复标题、口号与实现说明，原型边界和状态样例集中至“原型”入口；必要操作保留简短模拟提示。无“继续阅读”、第四类材料、词汇复习队列或自动模型调用。

## 独立 review

作者 root，独立 reviewer `desktop_design_review`。第一轮通过实际 UI 复现三项 P2：浏览器历史未保留资源身份、删除全部词本后返回详情报错、考试切换管理端时身份过早改变而跳过离开确认。集中修复为历史条目的资源上下文、失效资源回退列表及确认后再改变受众身份。另采纳默认声音保存与按钮文案简化建议。

第2轮定点复核确认三项 P2 全部关闭：历史返回恢复正确的「夏の手紙」；删除全部词本后返回 `#notebooks`，没有异常；考试切换管理端先显示确认，取消保留已选答案，确认后进入管理登录并能完成演示登录。默认声音选择英语后保存保持不变。复核脚本为 `review.cjs`、`review-exam.cjs` 与 `review-exam-followup.cjs`，相关流程没有 JavaScript 异常，未扩大为全项目审查。
