# 查询与回答收藏

状态：2026-09-24，P0 已确认、正式业务待实现。HTML 原型仅展示内置回答与当前页面内存收藏，不调用模型。卡片结构由 [AI 与朗读](ai-speech.md) 维护，运行由 [Agent 运行层](../architecture/agent-runtime.md) 负责。

## 1. 入口与范围

“查询”是手机与电脑的独立主入口，采用聊天界面。用户可以直接输入任意主题的问题，不要求先导入材料、选择单词或指定语法；支持词义、语法、句译及一般问答。材料仍只有小说、课本、试卷三类，查询不是第四种材料。

页面包含会话消息、回答卡片和输入框。手机优先保证输入、发送和收藏触控面积；电脑限制聊天行宽，输入区保持可见。Enter 换行，Ctrl/Cmd+Enter 发送；中文输入法组合期间不提交。空白问题不可提交，长度上限由契约统一发布。发送前保留草稿，失败/结果未知时可恢复原轮次，不自动重发。

查询沿用 AgentThread/Message/AiRun，线程标记 `mode=query`；阅读中的 Agent 标记 `mode=contextual`。自由输入允许无材料引用；用户显式附带的收藏/材料另验来源权限。历史每轮保留当时的解释语言及可选目标语言；一般问答无需先选择学习语言。

## 2. 回答与收藏

1. 用户主动发送后，服务检查 agent.use、本人模型配置和调用上限，创建有幂等键的轮次。无 Key 仍能浏览本人已保存消息和卡片，不生成假回答。
2. 流式文字展示处理中/停止状态。只有完整通过类型、来源和业务校验且已持久提交的卡片可以收藏。WordCard、SentenceCard、GrammarCard、AnswerCard 按各自类型呈现；一般问答使用 AnswerCard，不硬转成单词。
3. 点击收藏打开归类弹窗，可选零个或多个本人同语言单词本；未选择进入全部收藏/未分组。语言不明时先由用户确认卡片目标语言，不能无提示塞进当前词本。正文、例句、解释与来源组成版本化快照，不能只存标题。
4. 提交 `card_id + card_revision + notebook_ids`；卡片无明确目标语或为混合语言时，另提交用户显式确认的 `confirmed_target_language`。服务重取本人已提交卡片：已有明确目标语不得被此字段覆盖；无明确目标语时验证受支持语言值、用户确认与所选词本语种一致，再保存收藏的语言。语言确认不改写历史卡片，解释语言不自动充当目标语。不接受客户端自报卡片正文或 owner。幂等请求摘要包含确认语言和归本选择，同键异载荷冲突；本人同一卡片版本只建一条收藏，已有收藏的归类/语言变更走独立带版本更新，不能借重复收藏静默覆盖。界面在提交成功后才显示“已收藏”。归类失败保留选择并报告原因。
5. 收藏结果在单词本条目列表可搜索和查看；详情为弹窗。修改归类不复制内容，不刷新“加入日期”，删除单词本保留收藏。单词进入每日单词；语法、句子、回答卡片保留各自类型。

自由输入与模型生成例句不伪造书籍、段落或网页出处。已有材料引用继续保留合法 locator；没有来源时显示查询来源。任意主题输入不等于具备联网搜索、访问外部账号或执行任意工具的授权，首版不据此增加浏览器、任意 URL 抓取或管理工具。

## 3. 权限、持久化与异常

历史/卡片使用 agent.read；生成使用 agent.use；收藏使用 collection.create 和卡片读取权限，归本另验 vocabulary_notebook.read/update；读取收藏使用 collection.read。任一来源或工具操作逐次检查当前权限；一般问答不能绕过考试题面/答案隔离。所有会话、卡片和收藏按当前用户隔离，退出后停止订阅、清理私有内存，丢弃旧账号迟到响应。

模型不可用、输出校验失败、取消和网络中断分别显示真实状态；部分文字不作为成功卡片。恢复先读取原 run 快照，不能为恢复卡片再次调用供应商。成功结果自动持久保存，收藏只增加用户组织关系。日志沿用事件白名单，不记录问题、回复、卡片正文或 Key。

## 4. 验收

| ID | 待实现行为 |
| --- | --- |
| QRY-01 | 三端可直接进入查询，无材料也能提出一般问题；输入、换行、快捷发送、草稿与无 Key 状态正确 |
| QRY-02 | 四种卡片完整校验后可操作，半截/失败结果不可收藏；一般回答不伪造出处或学习证据 |

| QRY-05 | 停止、断线、窗口外恢复、账号切换和权限撤销不重复生成、不串消息或泄露卡片 |
