## 已实现

- [必需用例清单](../../../scripts/quality/required_cases.json) 显式登记层级、runner、平台、受众、传输、参数、责任分片和精确节点。B0-quality 为局部范围；完整 B0 保留 SCF-01～06 的各平台程序断言，不因缺实现/报告缩减矩阵。
- [结果检查器](../../../scripts/quality/cases.py) 分别核对 collection/result，要求相同 commit、构建标识、配置、工具清单摘要与 run_id。空/缺报告、错驱动、缺参数/分片、skip/xfail/xpass/deselect、中断和未处理失败均拒绝；重试不能覆盖首次失败。procedure 通过需独立 reviewer、带时区审查时间、逐条必需断言和非空证据文件摘要。
- [unittest 收集器](../../../scripts/quality/unittest_runner.py) 与 [pytest 插件](../../../scripts/quality/pytest_plugin.py) 从真实框架结果记录每个节点；pytest 记录选择器排除及 setup/call/teardown 失败，不把进程退出0复制成全部 passed。
- [源码/覆盖检查器](../../../scripts/quality/coverage.py) 核对所有 backend/app Python 与 frontend/lib Dart 手写源，显式核心分类、生成来源/精确输出及纯声明例外。缺源、未分类、核心空集、报告缺文件/分片/损坏、未知路径、假生成物、零分母或不达阈值均失败；分片命中取并集，按语句/分支或可执行行加权。
- [固定资产](../../../testdata/assets/manifest.json) 只有一份英/日自建 Unicode 文本索引，校验摘要、大小、语言、来源、许可与 canonical-text-v1。[场景](../../../testdata/scenarios/b0-static-assets.json) 采用严格 JSON、只读静态配方，拒绝未知字段/配方、可执行 YAML、秘密参数与错误引用/别名；不创建账号或业务成功结果。
- [CI 入口](../../../tools/ci/README.md) 和 GitHub Actions 参考文件固定 action SHA、SDK 版本、只读权限及明确平台；当前仓库没有远端运行或分支保护证据。

## 统一 B0 聚合入口

统一开发入口现支持 `check --stage B0 --identity <候选JSON> --report <报告> ...`，每份报告显式传入，调用原有完整 `cases --scope B0 --phase result` 检查器。缺 identity/report、下游失败、缺矩阵或非 passing B0-result 均失败；B1/B2仍拒绝，其他局部scope不接受这些参数。不自动发现报告、不改变必需矩阵、不重跑应用测试。

输出采用本次唯一run ID，机器记录明确验收针对显式候选身份、未执行远端CI、未重跑测试，也不自动宣称当前HEAD通过。新增3项命令接线/失败传播测试、既有无证据拒绝1项及邻接bootstrap保护1项通过；Ruff与strict Pyright通过。root作为非作者独立核对参数转发、完整门禁调用、结果读回、失败传播和明确候选边界，第1轮结论无阻断项。最终11项procedure与33自动节点的真实聚合结果另记[B0验收](2026-09-22-b0-acceptance.md)。
