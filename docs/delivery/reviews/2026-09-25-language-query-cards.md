# 语言查询与学习卡片

日期：2026-09-25，阶段1内原型与产品文档小阶段 DESIGN13，基线7e53173。用户进一步要求查询仅服务语言学习、改善卡片、取消词本中的通用回答卡片，并压缩词条占位。本阶段修改手机/电脑HTML原型及直接相关规格，不涉及Flutter、后端或数据库实现，不改变B0已验收、B1/B2未实现状态。

## 体验问题与方案

| 用户要求 | 本次调整与原因 |
| --- | --- |
| 查询纯粹，只能语言相关 | 输入区提供单词、句子、语法、习题四种任务；单词包含短语，句子任务允许文章翻译。图片只用于语言句段翻译/语法或习题批改；单词任务附图时保留草稿、提示选择图片用途。非语言需求不给通用回答或收藏入口 |
| 卡片更加精美 | 共用分类型卡片：单词突出读音、词性、释义及编号例句；句子突出译文和句段；语法使用规则与并列对照；习题展示原作答、建议订正及依据。统一蓝色边线、间距、标题层级和收藏操作，手机自动堆叠，保留浅/深主题 |
| 取消词本中的回答卡片 | 查询直接给WordCard/SentenceCard/GrammarCard/ExerciseCard，按实际类型完整收藏。移除answer类别、通用卡片模板和筛选；习题作为独立类型保留订正内容，不显示单词掌握状态 |
| 单词列表紧凑 | 词形/读音与释义构成摘要行，手机常规条目约66px，电脑约64px；宽屏释义并排，长文本只在摘要截断。整行至少44px可操作，完整例句、出处、掌握和归本在详情中查看 |

输入区改为结果之后的正常文档流，避免原悬浮输入遮挡卡片；发送后定位并聚焦新结果，卡片底部“再查一个”返回完整输入区。首次进入仍优先输入，示例只追加草稿，不自动发送；选择任务不清除附件或已有文字。

## 产品与实现边界

同步产品总览、查询、AI卡片、词本、收藏、习题选源，以及Agent、数据、API、权限和CSV规格。正式查询请求明确query_task，输入与输出均需校验实际语言任务；使用外语提问不代表可以执行百科任务。通用AnswerCard/answer不再是有效类型，习题查询批改仅供学习参考，不创建正式作答/成绩、掌握证据或自动错题记录；这些仍遵循独立习题与考试的有效评分流程。

旧DESIGN6～12交付记录保留历史描述，由当前决策覆盖自由问答与通用回答方案。正式收藏类型与接口仍待业务实现，本次没有数据库迁移或用户数据删除。CSV仍只处理单词，习题卡片不扩展其备份范围。

HTML原型精确匹配四个内置语言样例，其余输入提示范围与未生成状态；这不代表语义识别已实现。图片仅本机预览，不上传、OCR或调用模型，含图结果明确“图片尚未识别”且不可收藏；不会将内置文字答案冒充图片结果。内存收藏保留分类型完整载荷，刷新复位。

## Review与修订

作者root，独立reviewer `prototype_review`。第1轮限定本次diff与直接影响，并在Edge手机320px、电脑1440px实际体验。发现两项P2：收藏成功禁用按钮后焦点落到BODY；“再查一个”仅聚焦输入框，可能使发送按钮留在视口外。另有一项P3：已有收藏的旧sentence字段在详情重复显示例句。

集中修订：收藏成功关闭归类弹窗后聚焦对应学习卡片；“再查一个”将整个输入区居中滚入视口再聚焦；详情统一由学习内容渲染器呈现一次例句。补充上述定点断言，并清理电脑CSV提示中的旧回答类别及历史测试中的失效选择器。

第2轮独立Edge在手机320px、电脑1440px复核：收藏成功聚焦对应卡片，“再查一个”完整显示输入与发送按钮，旧例句只出现一次，无JavaScript异常，三项缺陷均关闭。文档复核发现总览P0表格仍有一处“回答”类别，已改“习题”并在本轮确认；同时明确手动创建不提供习题类型。当前语言范围、图片三用途、四类卡片及不产生评分/掌握/自动错题的边界一致，无未关闭缺陷；未增加第3轮或扩展全产品审查。
