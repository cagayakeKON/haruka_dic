# 材料库操作层级修订

日期：2026-09-24。阶段1内独立原型小阶段 DESIGN8，基线 484a5b3。用户要求手机搜索融合header、导入恢复右下角，并降低手机/电脑材料详情入口的视觉权重。本次修改手机原型、两端共用的材料列表/样式及相关文档，正式 Flutter/Python、认证、任务协议与依赖未改。

## 交付内容

- 手机材料页以小型品牌图标、搜索与消息组成header；类型筛选固定为紧凑的四项。搜索直接更新列表，保持原输入节点和焦点，清除关键词不清除类型。品牌图标仍可打开原型说明。
- 导入材料恢复为右下角悬浮主操作，位于导航之上，列表末尾有足够滚动空间；搜索聚焦时暂时收起。保留原三步导入与返回路径。
- 两端详情只显示每项右上角的18px更多图标，命中区域44×44px，没有文字列或分隔栏。键盘也可打开详情并在关闭后返回触发点；材料主区域继续直接阅读/学习/准备，解析中的材料进入进度。
- 将材料宽屏排版限定于电脑端；手机壳即使在735/1440px浏览器窗口中预览，也使用54px封面、四项筛选和紧凑搜索。没有更改电脑搜索与导入位置。
