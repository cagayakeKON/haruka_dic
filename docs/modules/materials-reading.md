# 材料导入、书库与公共阅读能力

状态：设计基线，2026-09-23；全部为待实现设计。需求依据为 [PRD](../product/overview.md)，公共响应、版本冲突及幂等以 [API 契约](../contracts/api.md) 为准，执行与事务以 [数据与任务](../architecture/data-jobs.md) 为准。本文只维护三类材料共用的导入/书库及小说、课本共用的出处/阅读位置操作；上传后的公共来源层与三套领域对象见[解析数据结构](../contracts/material-structures.md)，专用流程分别见 [小说](novels.md)、[课本](textbooks.md)、[试卷](exams.md)，类型字段与分派规则见 [三类材料契约](../contracts/material-types.md)。

DESIGN23的格式分派、原书ruby与OCR阶段复用统一见[提取契约](../contracts/source-extraction.md)。可靠文本直接提取，扫描/图片文字使用本人视觉大语言模型；原件注音与后续NLP补充读音分开保留。正文发布后事务登记[基础NLP](../architecture/text-analysis.md)任务，按章/有界单元处理并随文字加载标注，不在长按时调用模型。

## 1. 范围、入口与权限

| 功能 | P0 | 后续边界 |
| --- | --- | --- |
| 文件导入 | 显式选择小说/课本/试卷，MD、EPUB基础格式；既有本人试卷可追加专用UTF-8文字听力稿 | 小说/课本PDF/OCR/TXT为P1；文本PDF/扫描试卷范围仍待确认；原始听力音频上传/自动绑定为P1 |
| 书库 | 三类/语言筛选、标题搜索、分页、详情、改标题、显式按另一类型重新处理、删除 | 不增加其他材料类型、共享书库、公开市场或整库导出 |
| 小说 | 独立连续阅读器，目录/选区/进度/书签 | 专用处理和后续范围见小说模块 |
| 课本 | 独立单元学习页，课文/词表/习题分区与逐题反馈 | 专用处理和后续范围见课本模块；试卷必要校对仍为 P0 |
| 出处 | 版本化锚点、跨平台选区、原文回跳、重解析重绑与删除后快照 | 全文语义检索和跨材料关系检索不作为 P0 依赖 |

书库需要 `client.material.list`，阅读/目录/内容需要 `client.material.read`；进入时先取得当前访问快照，再请求本人数据。没有导入权限时空库提供说明，不展示可提交的导入按钮。无 Key 不阻断确定性提取及已经可读的内容；扫描/图片文字必须等待本人视觉模型配置与明确授权，不能用“已上传”冒充可读，规则见 [统一视觉OCR](../architecture/vision-recognition.md)。

本专题新增权限草案为 `client.material.reparse/analyze`、`client.reading.progress.update`、`client.bookmark.read/create/delete`（斜线表示独立代码）。全部 scope=self，由 [权限目录](../contracts/permissions.md) 登记；所有入口仍遵守 [RBAC](../architecture/authorization.md) 和 [认证与隔离](../architecture/authentication.md)。读取授权不隐含写进度/书签授权，导入/重解析权限不隐含AI 分析权限。

## 2. 流程、状态与异常

### 2.1 导入与恢复

#### 正常操作

1. 打开“导入”，先选择小说、课本或试卷，再通过系统文件选择器选文件。按所选类型展示可用格式、大小上限、仅日语/英语的目标语选项与专用准备步骤；保存 requested_stages，分别选择直接提取文字、需发起供应商调用的视觉识别和进一步结构/学习分析。视觉识别页/区域、模型与上限确认按统一视觉OCR协议；只选直接提取不自动识别扫描部分。取消文件选择不创建导入任务。
2. 前端检查扩展名和体积供即时提示；后端再次检查真实文件类型、日英语言能力、配额、权限与剩余存储；明确其他目标语在创建意图前拒绝，内容识别后按[语言准入](../contracts/material-types.md#11-首版材料语言)复核，未确认或不支持不得发布可读正文。普通材料要求 `client.material.import`；试卷同时要求 `client.exam.import`。
3. 创建短期 `MaterialImport`/上传意图；客户端只获得临时 staging_key 的受限写入能力、大小限制和到期时间。完成确认按 [不可变对象发布协议](../architecture/data-jobs.md) 领取 completion_generation/租约，由服务端复制/流式写入其独占的新 final_key，再校验 final 对象真实字节、大小、完整摘要和格式，不相信客户端 MIME 或先前 staging HEAD 结果。
4. final 对象通过验证后，PG 事务重查所有者/当前权限、意图有效性、completion_generation/租约与未取消状态，再发布 FileObject、Material、初始解析 Job 和 Outbox，返回材料与任务 ID。重复确认同一意图和相同载荷返回同一结果；相同幂等键用于不同载荷返回冲突。客户端从不获得 final_key 的 PUT 权限，重试不覆盖已发布对象。
5. Worker 只读取该已验证的不可变 final 对象，先运行安全格式提取器，再交给所选类型的专用处理器。MD 保留标题/列表/表格/代码；EPUB 按包清单/spine 取正文。源 ID、文本及定位由应用维护；获准格式的扫描内容由统一视觉模型提供转写候选，经校验标注来源后由程序发布，不允许改写既有正文。临时对象被重复 PUT、复制中变更或发布失败按中央协议拒绝/清理，不交给 Worker 未验证字节。
6. 小说发布可靠正文后可阅读，已有目录不等模型重新切章；课本发布可靠内容后可在专用单元页学习，未分类内容标“待整理”、未准备题目单独受限；试卷进入准备/校对，必须冻结通过才能开考。三类质量门槛分别由其模块定义，解析不完整不能静默标成完整成功。
7. 已明确请求的视觉OCR和进一步AI结构建议/语言提示/抽题分别记阶段，另需 `client.material.analyze`、本人Key和上限，模型调用前重新检查后异步执行；使用各类型专用输出模型和质量校验。OCR按应用生成的源页/区域引用，后续分析仅引用已发布正文块。复合请求缺权限受理前拒绝，可另选“仅直接提取”，不得静默模型调用或默默只做一半。尚无Key可明确保存为“待配置后由我继续”，补Key不自动启动旧供应商调用阶段。用户类型/手动标题不被模型结果覆盖。
8. 质量页按小说章节/语言标注、课本单元/角色/题目、试卷题号/分值/答案关联分别展示异常与可用能力。选错类型走显式重新处理，不以切换皮肤代替。

#### 试卷文字听力稿

文字听力稿不是新的MaterialImport，也不替换主试卷文件。用户从本人试卷准备页选择UTF-8纯文本/Markdown文件，前端申请purpose=`exam_listening_script`的专用UploadIntent；后端重查exam.read+exam.edit、所有者、当前草稿版本、日英语言范围、格式/字符/容量和配额，仍经staging→独占final对象→实际字节校验后发布`ExamListeningScriptSource`。上传完成最多创建不触发模型调用的规范化任务；“AI自动解析/匹配”由准备页在用户明确提交后调用独立analysis-run，重新检查material.read+material.analyze、本人Key/上限并创建Job/Outbox。相同幂等键重复完成返回同一脚本源，换文件或修订文本创建新脚本版本。

P0上传能力目录不发布`exam_listening_audio`，后端也拒绝audio MIME、外链URL、普通FileObject ID或把材料附件purpose改成音频。脚本上传完成只生成“待解析/待绑定”状态：AI须提出听力题标记和脚本—题组/小题匹配候选，用户在试卷校对流程确认后才能生成TTS或参与ready；详细对象和门槛见[解析数据结构](../contracts/material-structures.md#5-文字听力稿ai候选与tts绑定)。

推荐文件上限沿用 PRD：MD 20 MB、EPUB 50 MB；PDF 80 MB/TXT 20 MB 只在对应格式获准上线时生效。服务端配置同时限制解包文件数、解压后总量/单项体积、解析时间、图片尺寸和层级；具体值通过样本与容量测试定版，不能只限制压缩包字节数。上传限额按用户预留，完成/取消/超时释放，防止并行意图绕过配额。

EPUB/嵌入 HTML 不执行脚本、不加载远程 CSS/图片、不允许解包路径穿越或读宿主文件。外部链接作为用户显式打开的链接处理，不由解析 Worker 任意抓取。加密/DRM、损坏包、空正文、不支持格式给出安全错误类别；保留可说明的失败报告，不输出服务器路径或文件正文到日志。

语言不确定或声明不符时，进度面板读取Job的语言校对投影并允许在日语/英语内确认；主文件Issue挂本次待发布版本，追加稿Issue挂当前准备卷及确切ScriptSource。确认走现有Job retry的注册分支，按[发布前语言确认](../contracts/material-types.md#12-发布前语言确认与恢复)复核权限、输入及CAS后从已存提取结果继续；不要求先读正文或先调用AI匹配，未确定语言不先建ScriptVersion。

#### 状态与恢复

`MaterialImport` 状态为 `awaiting_upload → verifying → accepted`，分支为 `expired/cancelled/rejected`；复用本人源文件的重新处理不进入客户端上传阶段，直接由服务端验证后受理。源内容状态为 `parsing → readable/degraded/failed`，只表示提取可用性，不是试卷 ready；AI 分析状态独立为 `not_requested/pending_credentials/queued/running/ready/failed/unknown_outcome`。三类领域产物另外按模块判断可用状态，不替代 Job 的统一运行状态。未完全验证的上传不允许阅读或分析。

| 情况 | 用户看到的结果 | 技术处理 |
| --- | --- | --- |
| 文件选择取消/尚未完成上传 | 未导入；可重新选文件 | 撤销意图的新签发能力，临时对象按到期规则清理；已签 URL 的剩余有效期限制见认证文档 |
| 上传中断 | 上传失败，可重试 | 同一有效意图重试同一文件；换文件建新意图；完成确认幂等，不按文件名去重 |
| 相同文件已存在 | 提示已有材料，可打开或明确再导入 | 摘要只在本人范围比较；明确再次导入创建新 Material，不泄漏其他用户重复情况 |
| 原始解析失败 | 不显示“可阅读”，提供重试/删除 | 修复输入需新意图；可恢复任务按已提交阶段重试，不重复写正文 |
| AI 缺 Key/失败 | 小说可靠正文、课本可靠内容仍可用；试卷保留准备状态 | 更新配置后显式继续分析；不能绕过题目/考试就绪检查，不无限重试不确定调用 |
| 需要视觉OCR但未授权/缺Key/识别失败 | 扫描部分显示待识别/失败，已可靠提取部分明确标注覆盖范围 | 识别与进一步分析分开记录；纯扫描来源不能标readable，部分可用按专用质量门槛降级，不静默走其他OCR |
| 取消深度分析 | 原文和已提交分析仍可用 | 停止后续步骤；在途供应商可能已执行；不回滚可读版本 |
| 用户选择与 AI 建议不符 | 保留所选类型、提示不符项 | 不自动切换流程；元数据保存 provenance/revision，手动标题不被覆盖 |
| 撤权/禁用/删除期间 Worker 运行 | 保留已提交数据，后续受限步骤停止 | 领取、模型调用及提交前检查当前权限、所有者和 tombstone；无效旧任务不得让材料复活 |

重试需要当前 `client.job.retry` 并重新验证原业务动作、用户意图、来源和上限。取消只需有效身份/当前受众登录、本人的 Job、`client.job.cancel` 及可取消状态，不要求仍持有已撤销的导入/分析/生成权限；它不能启动新步骤或读取失权结果。查询需要 `client.job.read`，读取结果另验所属能力权限。关闭页面不等同取消。对已经存在的材料执行完整重解析还需要 `client.material.reparse`；其目的和影响必须在按钮确认页说明。

### 2.2 书库、详情、类型与删除

点击列表材料主区域直接进入该类型使用页：小说阅读、课本当前单元学习、试卷准备/校对（已有合法场次按考试恢复规则）。不先进入材料详情页。两端每项右上角保留小型“更多”图标，点击先打开操作菜单，提供“查看详情”和有权执行的“删除”。查看详情打开原元数据dialog，包含标题、类型、来源与解析状态；删除另行确认，并明确收藏与历史作答保留。关闭回到原列表与触发点，删除后移焦相邻材料，空列表回到搜索或页标题。图标视觉保持低权重，点击区域至少44px，具有材料名称的无障碍标签与键盘入口；不再单列大块“查看详情”区域。

手机顶部header默认显示“材料库”、搜索按钮与消息入口；点击搜索按钮后才切换为输入框、返回和清除。搜索期间保留关键词与类型，清除或关闭搜索只清除关键词，不取消类型；关闭后恢复标题，浏览器返回先退出搜索。材料导入保持右下角悬浮主操作，位于底部导航与安全区上方，列表末尾可滚动离开按钮覆盖范围；搜索展开期间暂时收起悬浮按钮。手机原型在宽窗口内仍按手机壳的可用空间排版，不能因浏览器窗口变宽套用电脑材料卡样式。

材料搜索忽略首尾空格。搜索或类型筛选无结果时说明当前条件，并提供“清除搜索与筛选”；真正空库提供有权的导入入口，手机此时使用空态主按钮。清除后恢复列表与可继续操作的焦点，不把无匹配描述成没有任何材料。

尚未发布可靠正文时显示“解析中”及[WebSocket实时进度](../contracts/job-progress.md)，点击进入进度面板，不渲染空白阅读器或虚构正文。断线显示连接状态并保留最后确认进度，重连补读快照，不重新启动解析。已有可靠正文可直接读，可选AI分析仍独立显示；失败、取消、待校对不能冒充解析中或完整成功。电脑端只保留右侧任务展开栏，站内消息只保留header入口；两者使用同一任务事实，避免重复任务入口。

书库默认“全部”，类型筛选只有小说、课本、试卷，语言可多选。按用户要求，不设“继续阅读 / 最近在读”区域，直接展示材料列表；小说显示阅读位置，课本显示最近单元/内容位置，试卷显示独立开考/继续/成绩状态。标题搜索为当前用户标题匹配，不声称已实现全文或向量搜索。按服务端排序键与 ID 稳定分页，切筛选清空旧游标，迟到响应不能混入新筛选。

材料卡显示标题、类型、语言、解析/分析状态和实际可用计数；估计阅读时长/难度标记为估计。缺元数据使用文件名等确定回退值，不伪造作者。详情页提供目录、质量报告、最近进度和有权执行的编辑/重试/删除操作。

改标题使用 `expected_revision`；已建立材料的类型不可原地修改。“按另一类型重新处理”创建新的材料和专用产物，权限、幂等、原文件复用与旧记录保留只在 [三类材料契约](../contracts/material-types.md#3-类型修改与重新处理) 维护。打开卡片按后端材料类型进入小说阅读器、课本单元页或试卷入口，不提供跨类型皮肤切换。

删除要求 `client.material.delete`，展示“移除原文和阅读入口；收藏/历史作答保留快照”的确认。先事务写 tombstone、停止新增任务/签名并从列表移除，异步清理未被保留业务版本引用的原文件/缓存。其他设备下一次访问返回已删除状态并清除相关缓存；不承诺离线设备即时清除。已有收藏/练习/考试历史的正文快照和必要题图由对应业务版本保留，不级联删除学习记录；保留的考试版本只经考试授权接口访问，不变成普通原文下载旁路。此操作不增加回收站/整库恢复产品功能。

### 2.3 共用出处、位置与书签

以下位置/书签规则只供小说与课本按各自结构使用，不代替考试场次/答题进度。进入专用页面先取得元数据与对应 manifest，再按章节或单元加载。状态区分加载、就绪、可用缓存、权限失效、版本变化、材料已删除和加载错误；局部加载失败可局部重试，不反复重新导入整本书。主题/字号变化只触发布局，不重新生成服务器锚点。

小说连续阅读、课本按单元学习的具体操作由各模块维护。共用文字选区、书签和来源返回；主题/字号来自偏好。朗读高亮只表达当前已确认播放的片段，不能仅按估计计时跳句。选区工具栏统一只有朗读/查询，完整查询结果再收藏，交互由[AI与朗读](ai-speech.md#21-全局选区交互)维护；分别检查实际动作与来源权限；阅读权限不自动允许模型调用操作。解释/TTS 见 [AI 与朗读](ai-speech.md)。

阅读位置保存 `last_locator`、当前内容版本、`revision` 和服务端接受时间；小说另保存 `furthest_locator`，同版本按内容顺序单调增加，不能用它覆盖回读位置。课本保留最近单元/角色块位置，不使用全书最远位置推断单元完成；练习状态由 Attempt 单独维护。小说阅读百分比只按确定文本顺序估算，不作为学习完成证明。

在线时按停留/章节切换/离开页做有界防抖保存；每次带 `expected_revision` 和本地递增操作序号。多端冲突返回服务器位置，界面提供继续本设备当前位置或跳到服务器位置，显式选择后用最新 revision 再写，不用客户端时间戳悄悄覆盖。没有写进度权限时阅读可用但提示不会跨设备同步；离线仅保留本次视图位置供当前页面使用，不排队业务写入。

书签保存 locator 与可选短标题，创建/删除幂等；重复点击同一精确锚点提示已存在，可直接定位。P0 不做书签全文搜索或层级文件夹。阅读历史记录当前用户的已接受打开事件与位置，计数依据业务表，客户端埋点不直接写学习统计。日后删除/重解析按出处状态显示，不抛出不可恢复页面错误。

课本单元、词表和逐题反馈规则见 [课本模块](textbooks.md)，整卷作答与成绩见 [试卷模块](exams.md)。共享文本组件和题型控件不代表共享页面或业务会话。

### 2.4 出处回跳与新版材料

收藏、卡片、错题和书签的“在原文中看”先解析当前可访问的出处，再打开所引用版本并高亮。来源已删除或无法唯一定位时保留业务快照并显示具体不可用原因；失去读取权限时不给出受限上下文，也不按同名材料猜测关联。

新内容版本发布后提示用户重新加载。重解析失败仍可读当前版本，已有收藏、作答与考试继续保留原版本来源；阅读选区和播放队列不能在后台无提示切换文本。唯一重绑与歧义处理执行公共出处协议，界面负责展示可跳转、待重新定位或仅快照状态。

## 3. 前端职责

页面结构、长按/键鼠路径、阅读定位在重排后的恢复和性能要求遵循 [Flutter适配规范](../engineering/flutter.md)。下面平台表维护系统差异；紧凑/宽屏布局按实际窗口空间选择，不将Android固定为小屏或Web固定为桌面。

公共入口负责类型/文件选择、导入进度、书库过滤与稳定列表，再分派到各类型专用质量页和使用页面；选区、书签和冲突提示可复用小组件。三类页面分别拥有业务 controller，不能建立万能阅读页面。主题/字号只改变布局，选区转换遵循公共出处协议；所有受限入口与深链接使用同一访问快照。

| 平台 | P0 操作要求 |
| --- | --- |
| Windows | 文件对话框、鼠标/键盘选区、目录快捷导航、缩放后出处映射；系统取消文件选择无失败弹窗 |
| Web | 文件选择/浏览器刷新/深链接、同源会话与 CSRF；缓存可被浏览器回收，重新联网加载；不能假定可直接读用户磁盘路径 |
| Android | 系统文件选择 URI、长按扩选、小屏目录、后台中断后查询已有任务；不要求宽泛存储权限完成基本导入 |

所有平台只在当前账号有效离线租期内展示已有阅读/音频缓存，失效、重新联网和账号切换见 [设置与缓存](settings.md)。

## 4. 后端职责

解析、类型分析、版本发布和清理在后端执行；前端关闭不等于取消任务。不可变上传发布、Job/Outbox、阶段重试及撤权后的提交规则直接采用公共契约，本模块不另建一套上传或任务状态机。

格式提取保留原文件、源顺序和定位证据，专用处理器再解释业务结构；不能先把所有文件压成一个 Markdown 再丢掉表格、题目和版面关系。下面是适配要求，库和参数在对应格式获准后用样本验证：

| 格式 | 共用提取职责 | 三类处理时的差别 |
| --- | --- | --- |
| Markdown | 标题/段落/列表/表格/代码及源行映射，内联范围由应用校验 | 小说保留段落章序；课本保留表格/内容角色；试卷识别题组/答案区，不能靠标题级别直接 ready |
| EPUB | OPF/spine/nav 顺序、正文、ruby/脚注/图片引用 | 小说围绕章节；课本重建单元及练习关联；试卷提取题目后仍校对冻结，不能展示 EPUB 正文代替考试 |
| TXT（后续） | BOM/编码检查，不确定编码先预览；保留原行与换行映射 | 小说校验分章/对话；课本谨慎识别编号/缺失表格；试卷逐题检查选项和答案，不推断格式丢失内容 |
| PDF/OCR（按批准范围） | 可用文本层直接提取；需识别部分渲染页图后统一调用视觉模型，保留页/裁切映射及质量报告，不伪造模型未可靠提供的字坐标 | 小说关注跨页断行/段落；课本关注多栏/图表/题目关系；试卷关注题号/空位/分值/答案配对。视觉识别成功不代表三类都可用 |

各类型独立生成类型化结果，模型只能引用既有原文范围，不能重写原文或直接生成可信业务 ID：

| 分析结果 | 持久化与展示要求 |
| --- | --- |
| 元数据 | 标题、原文存在的作者、主语言/其他语言、是否双语对照和难度估计；原格式元数据、人工值与 AI 推断分别标来源 |
| 类型适配提示 | 仅提示内容与用户选择可能不符，不更新 material_type；标签不改变处理器或入口 |
| 结构 | 小说章节、课本单元/内容角色、试卷题组分别校验；不保存成只有不同皮肤的通用结构结果 |
| 习题候选 | 题型、题干范围、选项/空位、答案和解析出处、所属单元；无原文答案不得伪装为原卷标准答案 |
| 可选学习提示 | 章节摘要、关键词、预估 CEFR/JLPT 难度；明确是弱估计，不把等级当认证结果 |
| 质量报告 | 识别类型、章节/题目数量、低置信度区域、失败页和可修复项；不完整内容不能静默标完整 |

M1同时交付[本人站内消息](../contracts/notifications.md)的列表/未读/单条与全部已读/按权跳转及NTF-01～05，不以任务进度代替持久消息。

深度分析完成后通过本人任务状态与站内完成提示告知结果；后端提交是完成依据，客户端不在线仍能之后查询。通知只带安全引用，不携带原文，也不扩成邮件/系统推送承诺。小说与课本的可靠正文不被可选分析阻断，课本练习与试卷开考分别执行自己的可用门槛。

文件上限与解包/像素/时间等限制由部署配置统一发布；1 MB = 1,000,000 字节。清理只处理没有保留版本引用的对象，不能删除历史复盘需要的内容。

## 5. 公共契约与依赖

[API 契约](../contracts/api.md) 是 `/api/v1` 路由、请求/响应、游标、幂等与版本冲突的唯一目录；[权限目录](../contracts/permissions.md) 维护实际动作代码。[解析数据结构](../contracts/material-structures.md)维护SourceUnit/ContentBlock与三类领域对象，[出处协议](../contracts/content-locator.md)维护完整定位字段、Unicode/文本规范化、回跳与版本重绑；本模块仅保留相应用户操作。

执行依赖 [数据与任务](../architecture/data-jobs.md) 的不可变对象发布及 Job/Outbox，[认证与隔离](../architecture/authentication.md) 的文件/账号边界，以及 [日志与埋点](../operations/observability.md) 的事件白名单。材料转考试由 [试卷模块](exams.md) 接管；普通练习、解释/朗读与离线缓存分别见对应模块。

| 业务操作 | 业务对象/结果 | 事件 |
| --- | --- | --- |
| 导入、查询/取消未接受意图 | MaterialImport、UploadIntent、FileObject、Material、解析 Job | material.import.requested/completed/failed/cancelled，附阶段 |
| 书库/详情打开、元数据更新/删除 | Material、阅读进度与计数投影、revision/tombstone | screen.viewed、material.opened/updated/deleted |
| 重解析与版本列表 | MaterialRevision、解析 Job | material.reparse.requested/completed |
| AI 分析 | 类型化分析结果、AiRun、Job | material.analysis.requested/completed/failed |
| 试卷文字听力稿上传 | UploadIntent/FileObject、ExamListeningScriptSource、可选规范化Job | exam.listening.script_uploaded；只记录格式/长度区间和状态，不含脚本正文/文件名 |
| 试卷听力候选分析 | 冻结输入版本、AiRun、分析Job与候选代次 | exam.listening.analysis.requested/completed/failed；候选不算人工确认，不含脚本/题面正文 |
| 章节读取与来源解析 | SourceUnit/ContentBlock、类型专用节点、Sentence、AnchorMapping | reading.chapter.opened、source.navigation.result |
| 阅读位置与历史 | ReadingProgress、ReadingHistory | reading.progress.saved、reading.session.ended |
| 书签 | Bookmark | bookmark.created/deleted |

来源解析允许业务引用 ID，不能成为任意 locator 访问私有对象的代理。事件仅允许阶段、格式、计数、状态、耗时和受控资源引用；禁止原文、文件名全文、选区、查询词、文件路径和签名 URL。前端打开体验、服务端保存进度和后台完成分析是不同事件。
