从 [原型入口](index.html) 分别进入[手机端](phone.html)与[电脑端](desktop.html)。两个入口分别拥有页面结构、导航、排版和交互脚本；共用虚构样本、基础图标/安全转义，以及 collections.js 的本地收藏/查询/任务示例交互、exercise-builder.js/css 的来源选择与范围预览；外层导航和布局保持独立。手机端以五个主入口、底部操作和面板完成触控路径；电脑端从单列布局渐进展开侧栏、阅读解释和设置分类，沿用手机视觉与五个核心目的地，并提供独立 Web 管理端示例。静态页面可直接打开HTML；WebSocket进度需要下面的本地演示服务。普通静态服务/直接文件方式没有进度服务器时会保留等待连接，不虚构完成。

手机底部只保留“材料 / 词本 / 查询 / 练习 / 我的”五个主入口；详情页隐藏全局导航，以顶部返回、当前页动作和必要的底部工具完成任务。材料导入保留在右下角悬浮按钮，收藏新增放在header；导入分步和逐题练习使用底部确认区。五个主tab的header显示h图标和当前名称，正文不重复标题；材料库、单词本点击搜索按钮才展开输入框，关闭清除关键词并保留当前类型/单词本。搜索展开时收起导入悬浮按钮，列表末尾可滚动至按钮上方；h图标可打开原型说明。两端材料更多图标保留44px命中区，点击先显示“查看详情 / 删除”，详情沿用原dialog，删除另行确认；关闭恢复触发点，删除后回焦相邻材料或空列表的搜索/标题。手机在宽窗口预览时仍按手机壳排版。浏览器返回先关闭底部面板或展开的搜索，再按习题步骤与页面层级退回；考试中返回先询问，离开后从准备页明确续答。各页面仍可通过导航或明确按钮进入；深链以 `#页面名` 表示，习题第二步使用 `#exerciseBuilder?step=2`。试卷作答与结果深链受当前演示状态限制，必须依次进入准备、开考、交卷。

电脑端宽屏保留五项侧栏，窄窗口改用底部导航；主要操作至少 48px，图标按钮至少 44px。表格窄窗口在自身区域滚动，键盘可聚焦该区域。`/` 定位当前搜索，Ctrl/⌘ + Enter 发送模拟对话；弹窗隔离背景、循环键盘焦点，Escape 关闭并回到触发按钮。导入和习题步骤可通过浏览器返回/前进；历史条目保留资源身份，已删除词本详情回到列表。考试离开先确认，准备页提供返回作答。

产品页面删除重复标题、功能宣讲、装饰性英文眉题和服务端实现说明。手机header的h图标与电脑“原型”入口集中说明虚构数据与内存边界，并提供空白、离线、失权、失败和加载状态样例；状态样例不再出现在产品设置菜单。文件、凭据、生成和考试仍保留影响当前操作判断的简短模拟提示。

DESIGN11 体验修订：收藏条目整行可点击，键盘 Enter/Space 打开详情，关闭后回到原条目；手机将切本与每日单词并列，压缩列表留白。材料/收藏分别区分搜索或筛选无结果与真正空库/空本；“清除搜索与筛选”同时重置两项并保留当前词本，页头的单独清除搜索仍只清关键词。材料/收藏搜索忽略首尾空格，收藏额外匹配读音。空态提供添加/导入或切本入口，关闭面板回到实际触发位置；空态因添加或切本成功而消失时，分别回到新条目或切本按钮。默认无hash入口返回阅读前页面时能恢复材料库，手机同页切筛选保留键盘焦点。

## 演示边界

- 全部材料、账号、消息、错题、用量与管理数据均为虚构样本，交互状态只留在当前页面内存；刷新会复位。
- 材料删除只移除本页内存中的材料和可用阅读/新练习来源，刷新后恢复；收藏、已有作答与错题快照保留。已删除来源不能通过旧阅读入口重新打开，迟到模拟进度不能使其回到列表。正式权限、持久删除与冻结记录保护仍待业务实现。
- 材料/CSV文件选择只记录文件名，不读取或上传内容；查询图片由浏览器读取以本机预览，不上传。图片临时URL在移除或退出时释放，消息中的图片保留到当前演示会话结束，刷新复位。CSV 导出只生成虚构样本；导入预览与所选文件内容无关。试卷首版文件格式仍待产品决策。
- 登录不鉴权，服务连接不联网，头像不接收图片，Key/密码流程不收集真实凭据；模型、OCR、TTS、Agent、听力播放及收藏保存均不调用业务服务；只有解析进度连接本机模拟WebSocket。模拟成功提示不表示服务器提交。
- 试卷结果只在本次本地交卷后显示；原卷 38 题仅为结构示意，本原型可操作 3 题。示例计时、题目和分数不代表正式考试的服务端时限、评分、证据和听力播放次数。
- 站内消息属于任务与结果提示，没有系统推送或邮件提醒开关；界面语言仅展示简体中文。学习语言支持英语、日语示意，不能推断其他语种已支持。
- 没有“继续阅读/最近在读”、词汇每日复习/SRS、第四种材料或跨用户私有内容入口。管理端只展示虚构运维摘要，不提供用户私有材料旁路。

正式 Flutter 页面、权限、离线租期、模型 Key、任务、持久化、无障碍和 Windows/Web/Android 适配仍以工程切片及对应验收证明为准。本原型的浏览器 CSS 阈值不是 Flutter 断点。

手机身份页使用顶部品牌与可滚动短表单，密码显隐不丢输入，错误贴近字段；切换页面后不恢复密码，邮箱只在当前页内存中临时保留。注册和找回均显示独立受理页；原型不创建账号、不发送邮件、不修改密码。注册长度用账号模块推荐值演示，正式输入约束仍由公开策略确定。DESIGN7 的局部检查见[手机登录、注册与找回优化](../docs/delivery/reviews/2026-09-24-mobile-auth.md)。

## 本地进度演示与检查

在仓库根目录执行（Python 3.9及以上）：

~~~powershell
python -m pip install -r prototype/requirements.txt
python -X utf8 prototype/serve.py
~~~

打开 `http://127.0.0.1:8767/desktop.html` 或 `http://127.0.0.1:8767/phone.html`。服务只监听本机：HTTP 8767、WebSocket 8768；按 Ctrl+C 停止。不连接正式数据库/队列/模型，服务端不接收上传文件；查询图片仅在浏览器本机读取预览。websockets固定12.0，仅为原型辅助依赖，不改变正式后端锁。

内置“雨上がり”在约60秒内接收服务端模拟进度，完成后可读其内置短文。文件导入同样只创建模拟任务，演示结束明确无正文；课本保留单元不可用状态，试卷保留准备/不能开考状态，不把虚构文件标成真实可读。服务端短期内存按每页随机会话分区，刷新重置；这不是正式认证、持久Job或生产WebSocket协议实现。

查询支持选择PNG/JPEG/WebP、本机粘贴图片、缩略图放大/移除和纯图/图文发送；原型限制每轮4张、单张10MB/2400万像素。手机“拍照”使用capture=environment请求系统采集，具体行为取决于浏览器/设备；桌面预览可能仍显示文件选择，并非原生Android相机/权限已交付。含图消息仅显示“未生成图片回答”，不会将内置文字答案冒充看图结果；取消/失败保留原草稿，退出清理图片与查询内存。查询提供四个可体验的内置问题；任意其他文本可提交并得到明确“未生成回答”的占位卡，不能当成真实AI回答。收藏保留完整卡片，类型分别进入单词/语法/句子/回答筛选。每日单词仅按实际本页加入日期显示单词，不生成任务或复习配额。
