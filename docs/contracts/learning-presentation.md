# 教材与试卷解析展示契约

状态：2026-09-23，已确认的展示方案，待实现。本文统一维护内容角色、作答交互、试卷听力呈现、结构关系、原文对照和降级规则；底层对象以[解析数据结构](material-structures.md)为准，业务流程分别由 [课本](../modules/textbooks.md)、[公共作答](../modules/vocabulary-practice.md) 和 [考试](../modules/exams.md) 维护。

## 1. 范围与分层

教材采用 **8 类内容展示**，试卷采用 **5 类作答交互 + 1 类题组容器**。这是组件和结构的分类，不是要求用户切换八种阅读模式，也不代表建立十四个独立页面。教材、考试分别编排页面、维护 controller 和业务状态，只复用无业务副作用的基础控件。

内容角色、业务题型和交互方式分别建模：一段课文可以出现在教材或试卷共享材料中；翻译、简答、作文可以使用相同文本输入控件，但保留各自题型、约束和评分依据。不能用控件类型决定评分方式，不能用内容角色改变 `material_type`。三类边界及格式能力仍见 [材料类型](material-types.md)；本契约不提前开放 PDF/OCR/TXT或匹配/排序控件。P0新增的是文字听力稿/正文候选经确认后生成TTS并播放，不包含原始音频上传、音频转写、录音作答或口语评分。

## 2. 教材的八类内容展示

| 内容角色 | 展示与操作 | 必须保留的结构 |
| --- | --- | --- |
| 课文正文 | 标题、段落、列表与正文选区；按实际权限查词、选句、解释和朗读 | 原书层级/顺序、源块和规范文本范围；注音、脚注属于富文本能力，不另造内容类型 |
| 对话 | 说话人、轮次、场景说明；选择一轮或其中一句学习/朗读 | 说话人与各轮对应，不按姓名合并所有发言；不默认生成角色声音 |
| 词汇表 | 词、读音、词性、释义、例句按条目对应；点读及收藏到本人单词本 | 原书列与条目关系；缺失列保持缺失，不由模型补成原文 |
| 语法讲解 | 句型、说明、使用条件和注意事项；可展开关联例句 | 原书讲解与例句引用及次序；未写出的语法规则不能伪装成原书内容 |
| 例句与译文 | 按原书关系显示例句/译文，译文可收起；分别选择和朗读 | 明确的对应关系，支持一对多及无译文；推断不确定时分开保留，AI 新增翻译另标生成内容 |
| 图片与图注 | 图文关联、图注、可放大查看；有原文描述时一并呈现 | 图片资产、图注和引用它的内容节点；不按距离猜配，不让整页截图代替结构化内容 |
| 通用表格 | 变形、分类、对比等表格，保留表头及行列关系 | 单元格、行列顺序及合并跨度；词汇表具有额外条目语义，不能把所有表格当词表 |
| 习题区 | 题干、材料、选项/空位、作答入口及普通练习的逐题反馈 | Lesson、题组/题目和练习引用；答案/评分依据走受控投影，不作为普通正文嵌入题面 |

Lesson 默认按原书顺序编排，例如“对话 → 词表 → 语法 → 例句 → 练习”。角色筛选、目录快捷入口只帮助定位，不将全部对话/词表搬到全书各自的大列表，不改变源顺序。嵌套结构允许语法说明引用例句、段落关联图表；同一源块可被引用，但不复制为新的原文身份。

答案页/附录是来源用途与发布策略，不是第九种学习展示。可读附录沿用上述角色，答案区按练习/考试专用规则关联和投影。未知块进入待整理内容与质量报告，不为凑齐八类强制分类；普通章节/块人工校正仍按既定 P1，不能借本契约引入通用文档编辑器。

## 3. 五类作答交互与题组

| 作答交互 | 对应题目 | 值与展示要求 |
| --- | --- | --- |
| 单选 | 单项选择、选择式完形的小题 | 选择稳定 option_id，不用显示字母/数组下标作身份；题面重排不改变选中项含义 |
| 多选 | 多项选择 | 保存 option_id 集合；选项数量约束、部分分和扣分规则来自冻结题目配置 |
| 判断 | 正误/是非题 | 未作答、肯定、否定三种状态可区分；默认未答，不能把 false 当未答 |
| 填空 | 单空、多空、行内文本完形 | 每空稳定 blank_id，保存空位到输入值的映射；保留句中位置及前后文，不按遍历次序重新编号 |
| 文本回答 | 翻译、文本简答、作文 | 共享文本编辑能力；按业务题型提供字数/长度提示与校验，保留独立 rubric 和评分方式；不硬编码同一字数限制 |

沿用现有 Exercise/ExamItem 业务题型，不将其枚举强行缩减为上述五项。普通练习只开放其已获准的题型范围；考试支持的作文不因此变成普通练习的首版作文生成能力。控件只提交用户答案，正确选项、允许答案、rubric、答案来源等按业务阶段由服务端处理。

**题组容器**保存一份共享材料和有序子题引用，用于阅读理解、完形等。共享材料可含段落、对话、图片或表格；每个子题使用上述交互之一，分别有稳定 ID、分值、保存状态。选择式完形使用选项控件，文本式完形使用空位控件；题组不是第六种答案格式。只对可评分叶子累计一次，共享材料和大题不重复计分；多空题的计分粒度由题目配置明确，不能同时把小题和全部空位各算一遍。

宽屏在可用空间足够时并看共享材料与题目，答题卡按剩余空间安排；紧凑页可展开/收起或单独打开共享材料，返回原题时保留答案、焦点和定位。该考试布局属于 P0；教材“讲解与练习同时分屏”的既有 P1 安排不变。

### 3.1 听力共享材料与题目标记

听力不是第六种作答控件，而是`ExamStimulus(kind=listening)`和题目的`delivery_mode=visual/listening/mixed/unknown`。听力题仍使用上述单选、多选、判断、填空或文本回答控件；一份脚本/音频可绑定有序题组或多道小题，Stimulus不计分，只有叶子题计分。

AI解析必须为全部疑似听力题返回有源证据的类型候选，并提出`ExamListeningScriptVersion → ExamStimulus → ExamItem[]`匹配；“听下面材料”、播放次数提示、听力大题标题、独立文字稿和题号范围都可作为证据，模型自报置信度不等于确认。客户端校对页分别展示脚本文本/说话人、候选题目范围、冲突/缺稿和答案泄漏提示，用户确认、修正、改绑或拒绝后才建立正式Binding。

考试题面只返回已冻结的音频清单、允许的播放控制和题目引用，默认不返回听力稿正文。交卷后脚本是否显示由冻结策略决定；alt、Semantics、缓存和媒体元数据都不能携带隐藏稿件、答案或rubric。原始音频上传/自动绑定是P1，不得把任意音频URL/FileObject作为P0 Stimulus。

## 4. 解析产物与后端校验

`TextbookManifest`维护Unit/Lesson与有序角色节点/关系、源引用和准备摘要；`ExamPaperVersion`维护题组/题目、阅读/图表/听力Stimulus、计分、听力AudioBinding和冻结版本，题面DTO仅投影当前阶段可读字段。完整公共来源层和小说/课本/试卷对象只在[解析数据结构](material-structures.md)维护；各自继续使用Pydantic模型，不新增一个承担多套业务状态的通用页面JSON。API包装沿用 [统一返回](api-responses.md)。

模型可以提出角色、分组及关系候选，应用负责稳定 ID、schema 校验、归属/版本和发布。结构至少能表达：原始顺序/层级，角色与源范围，说话人与轮次，例句与译文关联，表格表头/单元格/跨度，图片/图注引用，题组与子题/选项/空位关系。图片和共享材料必须使用受控引用，不能接受模型给出的任意外部 URL。具体字段由各领域输出模型单一维护，工程实现后单向生成客户端 DTO。

程序校验同用户/资料库/材料版本、树无环、引用存在、序号/身份唯一、源范围有效、表格跨度合法、计分一致、听力标记/脚本题目绑定已人工确认以及必要音频可用。未知角色、低置信度关系、未复核听力候选或残缺结构进入质量问题，不靠模型自报“成功”发布可靠内容。应用不执行模型生成的Flutter/HTML/CSS/JavaScript；客户端按支持的结构和控件白名单渲染。

分句和分词在所属源块内派生，不能把表格、对话轮次、图注或空位一起展平成连续正文。选词、TTS、高亮和出处统一遵守 [规范文本与定位](content-locator.md)，注音/译文收起、字号或布局变化不重写原文偏移。视觉模型只有页/区域可靠时按 [OCR定位规则](../architecture/vision-recognition.md) 返回页/区域，不伪造精确字符框。

产物保存 schema/处理器/内容版本，响应声明消费所需的结构能力。新客户端不重解释旧 source ID；旧客户端遇到未知的必需结构提示不兼容，不能静默跳过并宣称可完整作答。修正内容关系或重解析按材料与考试契约生成相应新版本，已开始场次保持原冻结版本。

## 5. 原文对照与考试内容投影

教材在学习页提供“结构化内容 / 原文对照”入口；MD/EPUB 对照使用安全的原始内容视图及准确出处，禁用原件中的脚本和自动外部资源加载，不承诺像素级还原。PDF 只有在相应格式获准后才提供原页定位。可定位时跳到源段/区域，定位不可靠时明确显示粒度，不用错误高亮充当识别成功。已有源内容的查看不触发新的付费识别。

试卷分开提供校对预览、考试题面和交卷后复盘。可能含答案的完整原件仅在本人校对范围且同时满足 `client.material.read`、`client.exam.read`、`client.exam.edit` 时提供，文件签名和出处解析同样检查；普通题面/场次/成绩读取权限不足以打开完整原件。答案和评分依据继续按专用接口的动作/状态投影，不能因为用户拥有文件就绕过接口约束。

考试中的图、表、听力和共享材料必须来自已验证的题面投影；图片使用确认只含题面内容的受控资产/裁切结果，听力只绑定已确认脚本生成并验证的私有AudioAsset。整页同时有题目和答案时，不能把整页图片、隐藏文本、图注/alt、Semantics、缓存或TTS当作题面出口；脚本来源落在答案/rubric范围时也阻止生成/ready。无法可靠分离必要题面与答案时列为完整性问题，让用户修正并重新确认。全文原件对照不作为考试中的失败兜底入口；已交卷复盘可按成绩权限读取解析/获准脚本，但也不自动获得原件校对权限。

## 6. Flutter 编排、适配与异常

教材由TextbookStudyController编排Lesson角色渲染，考试准备由ExamPreparationController编排听力候选/脚本/题目/音频待办，作答由ExamSessionController编排冻结Stimulus、播放器、题型控件和答题卡；领域各自注册可用renderer。复用文本/选区、图表、受控播放器和纯题型控件，提交/反馈/计时/权限动作留在各自业务控制器，不建立带`is_exam`分支的万能阅读器。

按 [Flutter规范](../engineering/flutter.md) 分别处理空间、输入方式与平台能力。复杂表格在小屏保留横向滚动/表头和行列语境，可提供单行详情；不把列拼成失去对应关系的段落。图片可放大但不挤走作答入口，长单元/题组按有界内容加载。译文折叠、角色导航和宽窄布局变化保留源定位；输入法组合、选中 option/blank、未同步答案及编辑代次不因重排丢失或重复提交。

功能控件沿用 [Test ID与无障碍](../engineering/testing/frontend-e2e.md) 的单一注册表，动态节点身份与业务 ID 关联；语义标签说明说话人、表格行列、空位及未答状态，不能用技术 ID 替代可理解标签，也不能含隐藏答案。注册组件不等于三端页面已验收。

| 异常 | 教材 | 试卷 |
| --- | --- | --- |
| 未识别块/低置信度关联 | 显示质量提示与有权限的可读原文；可靠部分继续学习，不伪造课程结构 | 必要题目/计分/共享材料不可靠时阻止确认 ready；明确问题位置与修复要求 |
| 不支持的题型/结构版本 | 提示该习题不可用；其他可靠内容可读，不算练习完成 | 不展示假作答控件；服务端发布门槛和客户端开考能力检查拒绝不完整作答 |
| 必要媒体缺失 | 标明受影响内容/练习，可重试读取；不默默删图 | 准备期阻止 ready；已开始场次保留已保存答案、提示故障及服务端截止仍有效。服务端确认必要媒体不可用后，相关评分待处理/待复核，不自动判错/记零；单端网络失败不直接改权威评分 |
| 听力候选/脚本绑定冲突 | 不适用 | 显示每条证据和待办；未确认听力题、缺稿、多脚本/题目范围冲突或音频未ready均阻止冻结，不自动改成文本题 |

确认故障必须按[考试故障处理](../modules/exams.md#必要媒体故障的场次处理)持久绑定冻结场次/媒体和受影响题目，锁卷/评分发布共同检查。恢复读取不抹去已受影响的作答事实；P0明确通过新场次重考处理，不能自动补答、无限重评或回流错误学习证据。

展示错误沿用统一错误/遥测出口，按白名单记录角色/结构版本、失败原因、数量和关联 ID，不记录原书、题干、答案或完整图片地址。呈现失败不能自动调用模型“修复”、切换材料类型或丢弃旧版本；显式重解析/重新处理仍走既有权限、预算和版本流程。

## 7. 验收与分期

以下是待实现的验收要求。阶段2验证解析、独立学习/校对预览、题面投影与能力门槛；阶段3补解释/收藏/TTS消费；阶段4验证实际练习、考试作答及复盘。按交付切片选择必要用例，不在纯文档修改时运行应用测试。

| ID | 通过标准 |
| --- | --- |
| PRES-01 | 八类教材内容在同一 Lesson 按原书顺序呈现；说话人/轮次、例句译文、词表列、图片图注、表格合并关系与独立人工标注相符，缺列/缺译文不补成原文 |
| PRES-02 | 五类交互正确映射业务题型，判断未答独立、选项/空位身份稳定；共享材料题组及多空题只累计叶子一次，普通练习与考试反馈时机独立 |
| PRES-03 | 原文对照回到正确内容版本/来源粒度；注音/译文折叠及布局变化不改选区/朗读范围，已有源查看无新模型调用；按实际获准格式举证 |
| PRES-04 | 仅题面权限不能获取完整考试原件；题面响应、图片/共享材料、alt/语义树、文件签名、缓存及TTS均无答案/评分依据旁路；校对/复盘权限与状态分别成立 |
| PRES-05 | 未识别/低置信度/未知schema/必要媒体缺失不被静默忽略：教材可靠部分仍可读，考试准备不能假ready；作答中服务端确认媒体故障→资源恢复/Worker重启→交卷，确认事实仍阻止误记零分及有效贡献，旧场次保留并可显式新场次重考；单端自报/锁卷后报告不能追认或清除故障 |
| PRES-06 | 三端按本阶段能力验证紧凑/宽屏、共享材料打开返回、大字/表格/图片、键鼠/触控/中文日文IME；不丢输入/位置/编辑代次，不重复请求或创建Attempt/Session |
| PRES-07 | 跨账号/错误版本/循环或非法关系均拒绝；旧场次不被重解析改写，账号切换及迟到响应不串内容；客户端不执行源/模型脚本或加载任意外部资产 |
| PRES-08 | 真实导入样本与人工结构预期核对，导入、校对、消费用例分开证明；质量提示和故障可经受控日志关联，日志不泄露正文/答案；未知角色保留可追溯来源 |
| PRES-09 | 上传文字稿和试卷正文提取两种来源均产生版本化脚本候选；AI标记全部疑似听力题并提出脚本—题组/小题匹配，用户确认/改绑/拒绝后才发布，迟到run不覆盖人工结果 |
| PRES-10 | 确认文字稿通过本人Key生成私有冻结TTS，缺稿/未确认/音频失败阻止ready；考试中隐藏脚本/答案，有限播放次数由服务端账本在跨布局/刷新/接管/并发与丢响应后保持，只有active在期限内续播且终态重播新领次数，媒体故障按首字节和场次事实处理；原始音频上传P0拒绝 |

测试素材与方法见 [数据规划](../engineering/testing/data.md)、[测试策略](../engineering/testing/strategy.md) 和 [前端E2E](../engineering/testing/frontend-e2e.md)。交互分类参考 [1EdTech QTI 3 指南](https://developers.imsglobal.org/spec/qti/v3p0/guide) 对常用题目交互的区分；这是设计参考，不承诺实现完整 QTI 导入、格式或认证。
