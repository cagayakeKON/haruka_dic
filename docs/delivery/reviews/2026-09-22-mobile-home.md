# HTML 原型 v0.4 手机主页与导航

日期：2026-09-22。范围：[HTML原型](../../../prototype/README.md)的手机主页、应用壳与预览入口修复小阶段；不计入Flutter或B0/B1/B2。

## 用户反馈与修复

用户指出手机主页仍缺少适配，并明确要求header、侧边栏等均采用手机交互。

- 手机顶栏直接提供标题、导入和偏好设置，移除重复品牌/标题及宣传区域。390×844首屏完整展示至少3份材料。
- 新增独立手机导航节点，四项分别为书库、收藏、练习和助手；桌面侧栏在紧凑结构中完全隐藏、菜单清空。阅读页用专属工具栏替代全局导航，返回书库后恢复。
- 导入/筛选/偏好使用手机底部面板；搜索不再因输入框有焦点而隐藏主导航。
- JS和CSS统一在小于1024px时进入紧凑结构，修复681～1000px且高度超过500px时回到桌面侧栏的空档。
- 新增[手机预览](../../../prototype/phone.html)，直接在390px视口运行同一份页面。它是预览容器，无独立业务状态副本。资源带v0.4版本；未认定缓存是此前问题根因。
