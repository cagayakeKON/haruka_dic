# Haruka「晴空频率」交互原型

状态：2026-09-24，阶段1中的独立原型小阶段 DESIGN2；手机端在 DESIGN3 调整任务流，DESIGN4 进一步重构移动排版、底部动作和产品文案。用于核对产品设计语言、页面信息架构和关键交互，不是 Flutter/Python 正式应用、B1/B2 实现或业务验收证据。视觉基线见[产品设计语言](../docs/product/design-language.md)，行为边界以[产品总览](../docs/product/overview.md)和各模块规格为准。

从 [原型入口](index.html) 分别进入[手机端](phone.html)与[电脑端](desktop.html)。两个入口分别拥有页面结构、导航、排版和交互脚本；只共用虚构样本与基础图标/安全转义辅助。手机端以四个主入口、逐层详情、底部操作和面板完成触控路径；电脑端维持宽屏工作台及独立 Web 管理端示例。可直接在浏览器打开 HTML；也可在仓库根目录运行 `python -m http.server 8765 --directory prototype`，再访问 `http://localhost:8765/`。不需要安装依赖。

手机底部只保留“材料 / 词本 / 练习 / 我的”四个主入口；详情页隐藏全局导航，以顶部返回、当前页动作和必要的底部工具完成任务。材料与词本的新增动作靠近屏幕底部，导入分步和逐题练习使用底部确认区。浏览器返回先关闭底部面板，再按习题步骤与页面层级退回；考试中返回先询问，离开后从准备页明确续答。各页面仍可通过导航或明确按钮进入；深链以 `#页面名` 表示，习题第二步使用 `#exerciseBuilder?step=2`。试卷作答与结果深链受当前演示状态限制，必须依次进入准备、开考、交卷。

产品页面删除重复标题、功能宣讲、装饰性英文眉题和服务端实现说明。首页右上“原型”集中说明虚构数据与内存边界，并提供空白、离线、失权、失败和加载状态样例；状态样例不再出现在产品设置菜单。文件、凭据、生成和考试仍保留影响当前操作判断的简短模拟提示。

## 演示边界

- 全部材料、账号、消息、错题、用量与管理数据均为虚构样本，交互状态只留在当前页面内存；刷新会复位。
- 文件选择只记录文件名，不读取或上传内容。CSV 导出只生成虚构样本；导入预览与所选文件内容无关。试卷首版文件格式仍待产品决策。
- 登录不鉴权，服务连接不联网，头像不接收图片，Key/密码流程不收集真实凭据；模型、OCR、TTS、Agent、听力播放及保存均不调用服务。模拟成功提示不表示服务器提交。
- 试卷结果只在本次本地交卷后显示；原卷 38 题仅为结构示意，本原型可操作 3 题。示例计时、题目和分数不代表正式考试的服务端时限、评分、证据和听力播放次数。
- 站内消息属于任务与结果提示，没有系统推送或邮件提醒开关；界面语言仅展示简体中文。学习语言支持英语、日语示意，不能推断其他语种已支持。
- 没有“继续阅读/最近在读”、词汇每日复习/SRS、第四种材料或跨用户私有内容入口。管理端只展示虚构运维摘要，不提供用户私有材料旁路。

正式 Flutter 页面、权限、离线租期、模型 Key、任务、持久化、无障碍和 Windows/Web/Android 适配仍以工程切片及对应验收证明为准。本原型的浏览器 CSS 阈值不是 Flutter 断点。
