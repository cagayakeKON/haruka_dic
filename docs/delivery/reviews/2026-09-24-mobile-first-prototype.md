# 手机移动优先原型修订审查

日期：2026-09-24。阶段1的独立设计原型小阶段 DESIGN3。用户指出手机端仍有缩窄电脑界面的痕迹，因此本阶段只修订[手机 HTML 原型](../../../prototype/README.md)及相应设计、导航和交付说明；电脑原型和正式 Flutter/Python 应用不在本阶段改动范围内。

## 交付行为

手机首页直接进入材料列表、搜索与横向类型筛选，移除占据首屏的品牌标语与大横幅。主导航收敛为“材料 / 词本 / 练习 / 我的”，详情页使用顶部返回，不常驻全局导航。小说以正文和底部阅读工具为中心，选词解释从底部面板展开；课本依次进入单元、内容、独立课后题；试卷一次聚焦一题，答题卡、交卷、离开确认与续答各有明确入口。习题生成按选源和题目设置分两步；Agent 采用消息流与底部输入区；词本、提醒和设置改用适合触控的列表层级。

页面之间共用虚构示例与本机内存状态。原卷 38 题仅展示结构，实际可操作题目是 3 道。计时、保存、模型、听力、登录和导入仍是演示，不代表业务服务已经实现。

## 独立审查与修订

作者为 root；独立审查由 mobile_first_review 执行。第1轮集中审查手机端交互，第2轮定点复核。两轮提出的问题均已修订，并由作者对最终行为做浏览器定点回归。

| 发现 | 修订与实际复核 |
| --- | --- |
| 关闭阅读底部面板会把正文滚动到顶部 | 保留同页位置；在 390×520 视口滚动正文、打开词语面板并用浏览器返回关闭后，滚动位置保持一致。 |
| 习题第二步没有历史层级，系统返回直接离开流程 | 第二步使用独立 URL 状态；浏览器返回及页内返回均回到第一步，不丢选源。三步导入也采用相同的逐步返回逻辑。 |
| 考试离开不确认，回到准备页后无法辨认是续答；38 题与实际 3 题混淆 | 增加离开确认、暂停后的“继续考试”页和题量说明；从材料详情进入试卷，开考、离开、返回材料详情、重新进入并续答的路径已验证。 |
| 第2轮发现保存离开后，旧作答历史仍可绕过续答入口 | 离开时回退到原准备页，暂停状态阻止旧作答历史重入；浏览器返回落到材料详情。续答后系统返回仍先询问，反复离开也不会重入旧作答页。 |
| Agent 长对话的新回复被固定输入区挡住，发送后输入失焦 | 发送后保持输入焦点，并将最新回复滚到输入区上方；连续发送 7 条后的最后回复可见。 |
