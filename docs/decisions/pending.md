## 2. 未锁定时的边界与关闭

无需等全部选择才能完成共同契约和无关工作，但依赖项未锁定时不能签署相应工程交付通过。中文在 MVP 的支持是界面/母语支持，目标语为英/日，不扩大成三套界面翻译承诺。试卷文件、注册/恢复、供应商和平台支持必须依据实际选择与验证标注，不能将推荐默认值写成已经可用。

关闭 OPEN 项时保留其 ID 和选择结果，记录依据、受影响的模块/架构/契约、验收范围及验证状态；不直接删除历史编号，也不以“文档完成”代替产品选择或工程交付。OPEN-10 的原需求与后续流程归 [收藏与练习](../modules/vocabulary-practice.md)，公共权限/API/历史数据约束需一并对齐。

B0/B1/B2 的允许缺席项与必须失败项见 [脚手架验收](../delivery/milestones/scaffold.md)，发布所需证据见 [交付验收](../delivery/acceptance.md)。未决选择不是隐藏已知缺陷的豁免通道，已承诺能力缺契约/测试仍须按相应门禁处理。
