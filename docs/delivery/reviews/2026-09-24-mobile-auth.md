# 手机登录、注册与找回优化

日期：2026-09-24。阶段1内独立原型小阶段 DESIGN7，基线 5ba1b24。用户要求优化截图所示手机登录、注册和找回密码界面。本次只修改手机 HTML/CSS/JavaScript 原型、对应局部回归及相关文档；电脑端、正式 Flutter/Python、依赖和认证契约未改。

## 交付内容

- 顶部小品牌与短声线统一三页视觉，取消整页垂直居中和外层白卡，主按钮靠近表单。找回入口靠近密码，创建账号和服务地址保留为清晰的次级动作；删除产品无用的解释文案。
- 输入标签常驻、16px 输入字号、54px 主按钮和至少 44px 点击区域。采用正常文档流和安全区留白，短视口仍可滚动到确认密码、提交与返回。
- 密码显隐保留原输入；支持邮箱键盘、自动填充语义、粘贴与键盘提交。就地错误含文本与读屏关联，提交聚焦首个错误，修改相应字段清理错误。
- 注册与找回分别进入受理页，明确本地模拟结果，没有创建账号、发送邮件或修改密码；注册后仍需显式返回登录，之后可以跳过首次引导。新鲜状态深链回到对应表单。
- 页面间临时保留邮箱，离开页面后不恢复密码，登录后清理邮箱草稿；密码不写入浏览器存储或网络。正式注册策略与恢复方式仍待确认，推荐长度仅用于原型演示。

## 独立 review

作者 root，独立 reviewer `mobile_design_review`。第1轮通过实际 UI 发现两项 P2：找回受理页替换 DOM 后缺少结果焦点/宣告；浅色占位文字透明度导致对比度仅3.67:1。集中修复为认证路由标题焦点、动态页面标题及连续历史事件的焦点保留，并取消占位文字透明度。标题不在交互 Tab 顺序中，程序聚焦不显示默认黑框；控件仍保留可见焦点。

第2轮定点核对修复代码与8个焦点/标题转换、2个配色组合的回归结果，确认两项 P2 均关闭，无遗留缺陷。普通校验失败仍聚焦首错字段；占位文字浅色5.64:1、深色7.66:1。reviewer 另实测320×360注册空提交，确认三处错误、首错焦点、主提交可达与无横向溢出，证据为 `artifacts/design7/review-auth-results.json` 和 `review-short-errors.png`。
