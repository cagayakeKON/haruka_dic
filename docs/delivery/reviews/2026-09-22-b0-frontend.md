# B0 前端契约与控件原型

本单元属于阶段1/B0，补齐前端契约消费者与基础控件验证。登录/收藏、用户凭据、业务缓存和任务仍属 B1/B2；不通过测试 fixture 暴露生产业务旁路。

## 实现

- Dio 5.11.1 按应用实例注入并关闭；环境页显式检查 `/health/ready`，展示加载、已就绪或本地化失败。页面销毁取消请求，宽窄切换不重复请求，不自动重试。
- `core/api` 集中处理信封、分页、错误、UUID/UTC/Decimal 字符串及可选值三态。204、字节下载/上传分别保留传输语义；代理 HTML、未知错误码和连接错误不会成为成功或泄露远端正文。
- 错误目录单向导出到 `api_catalog.dart`，ARB 是前端译文源；缺译文、未支持参数/占位符和正式 schema 漂移会使生成失败。
- 实际评估 OpenAPI Generator 7.25.0 的 dart-dio，现有正式 schema 的 `string | integer` 生成不完整 Dart 表达式；formatter 解析失败已重现。另发现非默认源码目录的 Windows URI 与 Optional 导入问题。按蓝图采用限 B0/B1 的手写 DTO 过渡，不将该失败原型声明为正式生成器通过。JAR 摘要、命令、配置和到期条件见 [原型记录](../../../tools/codegen/dart-api/README.md)。B2 前必须完成长期方案决策。
- 专用 `test_support/main.dart` 不被正式入口导入；控件 fixture 覆盖输入、禁用按钮、确认对话框、80 行虚拟列表和路由，用户/管理布局均可测。注册 ID 与正式应用同源，不能用技术 ID 替代可访问名称。
- `tools/e2e` 锁定独立 Playwright/TypeScript/Lint 工具；真实语义 input 聚焦后逐键输入。静态 fixture 服务器只回退明确页面路由，API 和缺失资源返回404；不采集 trace/HAR/登录存档。
