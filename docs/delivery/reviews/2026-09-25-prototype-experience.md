# 原型体验优化

日期：2026-09-25，阶段1内独立原型小阶段 DESIGN11，基线 dabcaec。用户要求以体验官身份体验现有原型并直接优化。本次沿材料列表→阅读→返回、收藏筛选→详情→返回及查询入口走查手机/电脑HTML；修改聚焦导航、收藏列表和空态恢复，不代表全原型或正式Flutter/Python应用验收。

## 问题与修改

| 体验中发现的问题 | 本次处理 |
| --- | --- |
| 手机默认无hash入口打开小说后，点击返回只改地址，正文仍停在阅读页 | 空hash按材料库处理；验证应用返回、浏览器前进/后退及阅读面板关闭 |
| 收藏文字区域无法直接打开，手机单条留白多、切本与每日单词连续占两行 | 每条收藏使用一个整行原生按钮，保留“查看”提示、类型/读音/释义/掌握或出处；手机合并顶层操作行、收紧条目间距，宽屏仍按列展示 |
| 筛选无结果与真正空库/空本提示混在一起，短语筛选为空却提示“换个词” | 区分条件不匹配与真正为空，提供清除搜索与筛选、添加/导入或切本入口；清除条件保留当前单词本，搜索忽略首尾空格，收藏可按读音检索 |
| 手机切换筛选重绘后焦点回到页面，键盘需要重新寻找位置 | 同页重绘恢复当前控件；清除条件后聚焦“全部”，详情关闭回到原条目及原位置 |

保留现有设计语言、五个主tab和原型内存边界，不增加继续阅读、复习队列、真实模型调用或持久业务。两端HTML资源参数同步到DESIGN11，避免浏览器沿用旧脚本/样式。
