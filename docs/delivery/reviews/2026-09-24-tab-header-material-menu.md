# 手机页头与材料操作菜单

日期：2026-09-24。阶段1内独立原型小阶段 DESIGN9，基线 cbc9c9d。按用户最新要求统一手机tab名称与搜索入口，并调整双端材料更多菜单。范围为HTML原型、局部浏览器回归和相关产品文档；正式Flutter/Python、认证、任务协议与依赖未改。

## 交付内容

- 手机五个主tab在header显示h图标与材料库、单词本、查询、练习、我的，正文不重复页标题。单词本新增收藏移到header，当前本、每日单词与类型筛选保持可达。
- 材料库和单词本默认显示搜索按钮，点击才展开输入框、清除与返回。筛选不替换输入节点；退出清除关键词，保留材料类型或单词本/收藏类型。浏览器返回先收起搜索，前进或从其他tab返回展开搜索时保持输入焦点。材料导入仍在右下角，搜索展开期间收起。
- 双端材料小型更多先显示“查看详情 / 删除”；查看详情进入原dialog，删除另行确认。取消不改列表，确认后移除本页内存材料；焦点返回相邻条目，空列表回到搜索或标题。刷新恢复演示数据。
- 删除保留收藏、已有作答与错题快照，旧材料阅读入口回安全列表，迟到模拟进度不能复活材料。已删教材退出新练习选源并清除旧候选预览；不变更正式删除与冻结记录契约。
