# 手机排版与文案重构

日期：2026-09-24。阶段1内的独立原型小阶段 DESIGN4。用户要求继续按「晴空频率」优化手机操作、排版并删除无意义说明文案。本次只修改手机 HTML/CSS/JavaScript 原型及相关文档，不修改电脑原型、共享样本、Flutter/Python 应用或业务契约。

## 交付内容

- 材料首页直接显示搜索、全部/小说/课本/试卷筛选与书目；放大封面、标题和元数据，任务入口放在标题旁，导入与新建词本放在底部可及区域。
- 导入使用三步单选、文件和摘要，下一步固定在底部；练习页区分显式选源生成与已有题目，单题页聚焦题干、选项、反馈与底部确认。
- 阅读保留纸面正文，字号、行距、字体和主题在底部面板直接调整；打开面板时隔离背景交互，键盘焦点受限于面板，关闭后回到触发控件并保留正文位置。
- 重整手机样式，统一主要控件至少 48px 命中高度，表单输入 16px，列表标题 16–17px，辅助文字主要为 12–13px；长标题可换行，固定操作留出底部空间，使用安全区和动态视口。
- 删除重复标题、说明产品如何组织的段落、装饰性英文眉题和技术规则宣讲。原型边界与状态样例移到首页“原型”入口；文件、Key、生成和考试保留必要模拟提示。无“继续阅读”、词汇复习队列或第四类材料。

## 独立 review

作者 root，独立 reviewer `mobile_design_review`。第1轮发现两项 P2 缺陷，均集中修订：小说 sticky 页头继承了透明背景，改为明确的阅读表面色；焦点恢复只识别首个 data 属性，改为组合所有稳定属性，避免教材第三项关闭后回到第一项。用量页实现术语清理建议也已采纳。

第2轮确认教材第三项焦点恢复正确、阅读页头不透明；发现主题派生后的标题仍继承应用底色对应文字，进一步给阅读页明确文字色并补齐阅读主题的蓝色控件角色。由作者按三种阅读主题定点检查页头、标题和词语面板，沿用未受影响的前述回归证据，不再开启全盘 review。

本阶段重构共用手机 CSS，因此必要布局检查覆盖其直接影响的 37 个手机路由；交互检查仅覆盖本次修改的控制与原有相邻任务路径。

- 本地 headless Edge 在 320×700、390×844、430×844 检查 37 个路由，共 111 个布局断言：无页面横向溢出，主导航仅出现在四个主入口。
- 验证材料筛选/搜索/清除，三步导入及返回保留选择，阅读面板焦点循环/Escape/滚动恢复/直接调排版，选源步骤返回/预览/确认生成，错误答案反馈，教材内容/作答，新词本长标题/新增词条，以及考试准备/开考/标记/离开/续答/答题卡/交卷。
