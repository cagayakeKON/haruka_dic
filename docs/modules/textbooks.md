# 课本导入与单元学习

状态：2026-09-22，待实现设计。“课本”与其他文档的“教材”是同一业务类型 `textbook`。类型边界见 [三类材料契约](../contracts/material-types.md)，共用上传/书库/出处操作见 [材料模块](materials-reading.md)；本模块独立于小说阅读和整卷考试。

## 1. 范围、入口与权限

导入时选择课本，打开后进入单元目录/学习页。P0 覆盖 Unit/Lesson、课文/对话/语法/例句/词表/习题区，按题型作答和逐题反馈；不把书籍字数百分比当学习完成度。P0 文件基础为 MD/EPUB，PDF/TXT/OCR 按产品优先级后续接入；单元完成度、讲练分屏仍为 P1。

内容读取使用 `client.material.read`，结构 AI 分析使用 `client.material.analyze`；练习、收藏、解释、TTS 分别检查实际动作权限。会读课文不代表可以生成或评分，缺 Key 不影响可靠原文和已有题的规则作答。

## 2. 流程、状态与异常

导入 → 保留格式结构 → 课本结构分析 → 生成单元学习页与质量报告 → 按可靠内容进入学习。确定性规则先识别原有标题/列表/表格/编号；AI 仅在明确请求时提出单元分组、内容角色及习题关联候选，所有引用由程序验证。

优先原书 Unit → Lesson 层级；无显式 Unit 时允许 Lesson/节直接位于书下，不强行补虚构课程。结构不明时放入课本自己的“待整理内容”，仍保留可读原文和顺序；不跳转小说阅读器，也不宣称完成课程结构分析。状态分别显示正文、单元结构和习题准备情况，不用整本单一 ready 掩盖失败单元。

| 内容角色 | 专用处理与学习操作 |
| --- | --- |
| 课文/对话 | 段落、说话人和轮次保留；选句、分角色文本展示、按选中段落朗读；不自动合成角色声音 |
| 语法/例句 | 说明与例句建立来源关联，示例和说明分别显示；解释与收藏仍带原始出处 |
| 词汇表 | 保留词、原书读音/释义、例句及表格对应关系；逐项点读/收藏/进入手动练习，缺列不编造 |
| 习题 | 题干、选项/空位、共享材料、答案/解析与所属 Lesson 关联；交给普通练习流程逐题反馈 |
| 答案页/附录 | 保留原书来源，将答案匹配到具体题目与版本；显示时使用练习投影，不直接嵌进题面 |
| 未识别/不支持块 | 保留可读原文与质量提示；未验证题型不生成假作答控件，不把遗漏的题算已完成 |

用户进入单元 → 选择课文/词表/练习 → 学习或作答 → 查看逐题反馈 → 按需重做/收藏错题。词表条目可收藏到本人一个或多个[单词本](vocabulary-notebooks.md)，进入其基础复习队列；课本不维护第二套SRS或掌握度。只有冻结到具体词条/义项的有效分项证据才回流[自动掌握](../architecture/vocabulary-learning.md)，看过一页不标记掌握。练习完成依据服务端Attempt；回到单元恢复当前位置，不能重新提交上次答案。

可靠题面已抽取但缺原文答案时可保留作答入口，评分依据按 [普通练习](vocabulary-practice.md) 显示待准备/AI 参考；无依据、AI 失败或待复核不计作零分。是否在导入时预生成教材参考答案仍为 OPEN-05，不把本次拆分当作默认付费授权。残缺题干/选项和错配答案阻止相应题的可用状态，不阻止其他可靠课文学习。

## 3. 前端职责

`features/textbooks` 拥有 TextbookStudyController、单元目录、Lesson 页、词表与练习入口。紧凑布局按单元逐级导航，课文/词汇/练习分区切换；宽屏可常驻课程目录和当前内容区。它不复用 NovelReaderController 或 ExamSessionController；小型文本、选区、词条和题型控件可以共用。

按 [Flutter规范](../engineering/flutter.md) 处理触控/键鼠、软键盘、焦点和独立空间布局。输入答案属于普通练习会话，不放在小说进度里；切分区或重排不能新建 Attempt。词表用有界列表，复杂表格保留单元格关联；不为适应小屏把原书词义列拼接丢失对应关系。

P0 只恢复单元/内容位置及实际作答状态，讲练同时分屏与单元掌握度不提前启用。来源回跳优先打开对应 Lesson 与角色块并高亮，不打开全书长文本定位同名句子。

## 4. 后端职责

TextbookProcessingService 负责单元、角色和练习引用的校验与发布，TextbookStudyService 提供课程结构和当前单元内容。TextbookManifest 维护目录与各单元准备摘要，正文引用共用不可变源块；Exercise/Attempt 仍由普通练习公开服务管理，不复制第二套评分/错题实现。

版面关系优先于纯文本分句：表格不能拼成小说段落，图文/编号/共享题干不能按距离随意关联，答案附录不能混进课文。语言标注可复用基础能力，但只在所属正文/例句范围执行；单元、题目与空位 ID 不由分句器或模型生成。

AI 分析提交校验树无环、引用同材料/版本、内容范围有效、题干与答案绑定唯一且来源可信；低置信度候选不直接成为可靠答案。结构产物记录处理器/schema/分析版本；应用程序生成 ID。重解析发布新内容版本，练习会话保持冻结题目及出处，迟到分析不能改写既有作答。

按单元加载和重试已定义的 Job 阶段；没有可复用已提交阶段时明确重跑范围/费用并由用户重新选择，不能声称支持任意模型内部步骤恢复。AI 失败只影响对应候选/单元状态，通用任务与删除并发仍按公共契约执行。

## 5. 公共契约与依赖

依赖 [API](../contracts/api.md)、[出处](../contracts/content-locator.md)、[普通练习](vocabulary-practice.md)、[数据与任务](../architecture/data-jobs.md) 及 [AI/朗读](ai-speech.md)。课本题与考试题可以复用纯题型控件；即时反馈、提交事务和评分发布使用各自业务入口，不能通过课本入口逐题提交考试答案。

材料事件附受控类型/阶段；单元打开使用注册的 `textbook.lesson.opened`，正文位置保存复用阅读位置事件，练习成功沿用服务端 practice/attempt 事实，不多计一次“教材作答”。所有事件经统一遥测出口，按 [观测规范](../operations/observability.md) 注册白名单且不记录内容/答案。

## 6. 验收

| ID | 操作与通过标准 |
| --- | --- |
| TBK-001 | 带单元、词表、例句和练习的 MD/EPUB 保留结构/列关系和顺序；无 Unit 不虚构，有歧义显示待整理且原文可查 |
| TBK-002 | 同 Lesson 的题干、共享材料、空位和附录答案正确绑定；错配/残缺题受限，不影响其他可靠课文，无答案不伪装标准答案 |
| TBK-003 | 三端专用单元页可完成课文→词表→已有题→逐题反馈；切分区/窗口不重复作答，题型控件复用不串用考试事务 |
| TBK-004 | 位置与作答分开，来源回跳到正确 Lesson/版本；AI失败/重解析不改旧题和成绩，非法类型/跨用户引用拒绝 |

同时执行当期 MAT/READ/TYPE、PRA 与适用 FLT 验收；当前尚未运行。
