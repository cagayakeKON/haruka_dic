# B0 数据库与受控初始化切片

日期：2026-09-22。阶段1 / B0 的局部交付；不代表完整 B0 或登录/RBAC业务已完成。

## 实现与边界

- [模型注册](../../../backend/app/models/__init__.py) 包含12张当前必需表：账号、私有库、权限、角色、角色授权、账号角色、菜单、注册策略、授权版本、种子版本、追加审计与授权Outbox。所有表统一UTC时间、中文注释、列来源/敏感度、作用域和逻辑关联元数据；没有物理外键、隐式级联或RLS。
- [数据库字典](../../../contracts/database-schema.json) 从模型单向导出，含模型摘要、列/约束/索引及逻辑关系；检查器拒绝空清单、缺时间字段/作用域/注释/关系、外键和重复索引。
- [初始化服务](../../../backend/app/services/initialization.py) 在受控维护连接、共同授权锁与单事务内创建种子或首管理员，同时提交授权版本、审计与Outbox。后者只保存授权通知，尚不投递，不算B2任务实现。
- [权限目录](../../../contracts/permissions.json) 展开文档登记的代码与初始角色模板，不使用运行时通配符。已有角色授权、显式拒绝、启停和注册策略不会被重复种子或新种子模板覆盖。注册默认关闭，管理菜单禁用；目录存在不表示业务接口可用。
- 同期已提交的单词本文档增加4个权限，目录纳入该增量并发布种子v2；已执行的开发v1记录保留。升级只登记新增代码，不给既有角色静默补授权限；新环境的只读模板仅包含词本read。业务动作依然留在对应后续阶段。
- 首管理员入口要求已匹配版本/摘要的种子，只创建首个受保护账号及私有库；拒绝普通已有账号提权、第二个首管理员及不合格角色。密码只经不回显终端输入并保存Argon2id哈希，重复执行不改密码。未实现公开登录、账号恢复、角色编辑或删除管理员。
- [迁移与schema检查](2026-09-22-b0-migrations.md) 由独立维护角色执行，迁移包由同版本sdist附带并显式指定绝对路径；包内CHECK基线通过importlib.resources加载。API/Worker/Outbox普通启动只读检查schema，不执行DDL/种子。
- readiness重新检查PG、schema、Redis、Kafka与MinIO，依赖失败返回统一503，恢复后可返回200；探针有5秒取消预算，阻塞SDK同时受已有I/O上限约束。live只表示进程存活。成功不表示B1登录/授权业务已可用。

依赖新增Alembic 1.20.0（迁移，MIT）和argon2-cffi 25.1.0（密码哈希，MIT）；使用已锁定SQLAlchemy/asyncpg，不增加第二套ORM或身份框架。密码参数固定为Argon2id低内存推荐档，参考 [argon2-cffi参数说明](https://argon2-cffi.readthedocs.io/en/stable/parameters.html)。
