# HTML 原型 v0.3 移动端重设计

日期：2026-09-22。范围：[HTML 原型](../../../prototype/README.md)的手机视觉与交互小阶段，不计入正式 Flutter/Python 工程或 B0/B1/B2 验收。

## 最终行为

手机使用独立页面结构，保留白/灰底色与蓝色 Primary。书库改为纵向封面行、顶部搜索、类型标签及底部筛选弹窗；收藏改为来源句卡片、掌握汇总和触控操作。阅读页独立于全局导航，底部提供目录、字号及朗读入口；查词使用原生模态底部弹窗。桌面保留原有杂志式布局和旁侧释义。

释义与收藏卡从实际点击位置提取来源句，避免将词典例句当成当前语境。阅读位置按段落及段内比例恢复；字号调整、横竖屏与桌面断点切换不只保留滚动像素。目录选择当前章节只关闭面板，包括从收藏出处进入的情况。

所有功能仍限于内存原创示例，刷新重置；真实导入、AI/TTS、考试、账号/权限与后端均未实现。不设“继续阅读”。
