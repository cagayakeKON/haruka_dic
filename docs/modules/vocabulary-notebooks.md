# 多单词本

状态：2026-09-24，DESIGN6 更新组织与浏览方式，正式业务未实现。单词本可组织单词、短语、语法、句子、摘录和回答卡片；同一收藏可入多本，单词共用学习状态。掌握只由有效习题结果自动计算。用户端不提供词汇复习、每日队列、到期提醒或 SRS；需要练习时从单词本显式进入[AI习题](ai-exercises.md)。

## 1. 范围、入口与权限

单词本是本人收藏条目的多对多组织方式，不是私有Library或课程。每个账号可创建多本，例如“教材A”“旅行”“考试词汇”；每本固定目标语，空本可改语言，有成员时不得使成员语种不匹配。

| P0核心能力 | 范围 |
| --- | --- |
| 多本管理 | 创建、名称/简介、列表/详情、删除；同一收藏入多本，加入/移出/移动不复制内容或学习状态；通过切换单词本弹窗管理 |
| 收藏管理 | 手动录入、阅读/查询卡片收藏时选本；按类型保存完整内容、出处与笔记；CSV/照片及标准词音仍仅适用单词 |
| 检索与批量 | 按本/语言/标签/来源/自动掌握/常错/是否排除出题筛选；稳定排序/分页；批量归本、移出、控制AI习题候选或明确删词 |
| AI习题入口 | 从单本/多本/全部单词进入AI习题条件页，可与时间、掌握状态、错题等组合；不自动生成或发起供应商调用 |
| 结果与历史 | 只读掌握摘要、实际习题/评分与错题历史；不显示下次复习、到期或每日完成率 |
| CSV | 全部/筛选单词与词本关系往返；不恢复可信掌握证据或错题/作答历史 |

使用 `client.vocabulary_notebook.read/create/update/delete`；词内容按collection权限，AI习题另验practice.generate、来源读取、本人Key和上限。每本、成员、计数和批量选择按owner/library隔离。公开词本市场、用户间共享、录音发音评分、完整离线编辑和智能规则本不在P0。

## 2. 流程、状态与异常

### 2.1 多本与成员

进入单词本直接展示收藏条目列表，默认“全部收藏”；保留当前本、类型、搜索与滚动位置。列表类型为全部/单词/短语/语法/句子/摘录/回答卡片；未掌握、已掌握、常错、已排除出题等学习筛选只适用于单词。“切换单词本”弹窗包含全部收藏、未分组和本人各本，可在同一弹窗流程新建、重命名、编辑简介及删除本；不再以词本封面页作为必经首页。系统视图不可删除，不算用户单词本。

创建本填写名称、目标语和可选简介；名称规范化只用于本人同语种去重。加入已有收藏须为本人同语种条目；加入另一本新增关系，移动则原子新增目标关系并移除指定来源，其余关系不变。重复加入幂等；外来ID、跨语言或并发版本冲突整批拒绝。

删除本先预览名称/成员数并确认，只删本和成员关系，不删词、音频、学习证据、错题或历史Attempt。删除单词是独立collection.delete动作，会移出全部本并阻止其成为新的AI习题主考目标；历史题答/错题保留快照，迟到任务不能复活条目。

只有kind=word的CollectionItem维护mastery_state，同一单词在多本共用一套状态；语法/句子/回答卡片不显示虚构掌握度。单词的不同义项/读音保持独立。聚合同拼写时显示各义项状态，不能把一个义项的成绩推广给其他义项。

### 2.2 录入、详情与编辑

手动、阅读划词、查询/AI卡片、CSV、照片均复用CollectionItem；CSV与照片只创建单词。创建时可选一个或多个本人同语种词本，无选择则进入未分组。点击“查看”只打开详情dialog，手机用可滚动底部面板，电脑用焦点受控弹窗；关闭回到原列表和触发按钮，不导航到独立详情页。详情按类型展示完整词形/规则/句子/回答、解释、原句/出处、笔记标签与所属本；单词另展示读音、标准发音、掌握摘要、习题和错题历史；各区分别验证collection/notebook/practice及来源权限。

缺释义、读音歧义或缺可靠题源显示待补全，不隐式调用模型。全局标准发音按[缓存规则](../architecture/learning-cache.md#51-收藏库标准单词发音的全局缓存)处理，播放不产生学习证据。

词形、语言、目标义项或读音实质变化推进learning_revision；笔记、标签和归本不推进。存在成员时，语言修改与加入/移动使用相同父锁顺序校验。有成员时拒绝改成不匹配语言，提示先移出。编辑页/API不提供mastery写入，也不存在due、调度参数或“下次复习”。

`exercise_control=active/excluded`控制是否进入默认AI习题候选；排除不改变掌握、错题或历史，用户仍可在AI习题页显式手选该词。删除、移出本和排除的含义必须分开。

### 2.3 检索、批量与统计

每本显示各类型条目数；掌握状态分布、常错、已排除、资料待补全及最近有效作答时间只统计适用单词，不把其他类型算成new。分类以CollectionItem去重；同词多本不重复计数。排序至少支持入本时间、词形、最近作答和错误次数，并以稳定ID打破并列。

批量选择区分当前勾选与全部筛选结果；后者冻结服务端选择快照/版本和条数。受控上限内原子执行，过大任务须预告分批语义、逐批重验权限并报告真实结果，不只处理当前页。

### 2.4 每日单词

“每日单词”是单词本中的独立入口，按日期查看当天新加入的kind=word条目，不是学习任务、每日推荐或复习队列。默认今天，可选择历史日期；日期按本人设置的IANA时区划分，界面显示所用时区。每日视图覆盖本人全部有权单词，不继承某一本的隐藏筛选；列表和计数使用同一服务端快照及稳定分页。

加入时间以CollectionItem实际数据库created_at为准，服务端将当地日期起止换算为UTC半开区间，正确处理夏令时和跨午夜。入本、移动、重复收藏、编辑、CSV跳过/补空不会改写加入日期或重复计数；CSV新建归本次实际加入日，source_created_at仅为来源历史。相同条目多本只计一次；独立义项/出处条目按各自ID计数。只有删除后显式重新创建的新条目产生新的加入记录，旧任务不能复活已删条目。

日期切换不产生生成/复习任务，不要求模型Key。没有条目时显示“这天没有加入单词”；不出现额度、打卡、每日完成率、due或SRS。语法、句子、摘录和回答卡片可在收藏列表按加入时间检索，但不混入“每日单词”。

### 2.5 从词本生成AI习题

条目列表提供“生成AI习题”，默认当前本；AI习题页可选多本或全部单词。可按收藏时间、入本时间、最近有效作答、mastery_state和常错筛选，预览候选/排除原因后确认。没有到期/逾期、每日新词配额、复习目标或自动队列。

生成流程、错题组合、快照/幂等/上限和验收以[AI习题](ai-exercises.md)为唯一正文。预览不调用模型，确认才使用本人Key；生成完成不等于学习或掌握，实际提交的有效结果才更新状态/错题。

## 3. 前端职责

Flutter使用NotebookRepository和NotebookController，独立紧凑/宽屏布局。Android与Windows/Web均以条目列表为首页，以切换弹窗管理词本、详情弹窗查看条目；每日单词另页展示日期与列表。批量操作使用选择模式，宽屏可增加列表列宽，但不恢复独立词本详情中间页。点击生成跳转AiExercisesController并带入本ID，不在词本controller保存模型Job或习题会话。

切布局保留筛选、selection和编辑草稿，不重复创建成员或调用AI。掌握状态只读展示原因摘要；排除/恢复候选使用明确文案，不能称为暂停/恢复复习。稳定Test ID与Semantics按前端测试规范维护。

## 4. 后端职责

NotebookService负责本/成员/批量事务；CollectionService负责各类型收藏内容及单词learning_revision；VocabularyLearningService只投影有效习题证据；AiExerciseService负责选择与生成。复用现有Python包、PG/Outbox/Worker，不新增服务。

Notebook与成员表含owner/library和UTC created_at/updated_at，成员唯一键覆盖本人/本/条目；无物理外键，关联由ScopeContext和共同父锁校验。索引覆盖owner/library、notebook/member、mastery、错误次数及稳定分页；实际DDL/查询计划实现时验证。

事件为notebook.created/updated/deleted、notebook.members.changed、notebook.exercise_control.changed等；不再定义review.plan或调度事件。日志不记录本名、单词、释义/答案或成绩正文。
