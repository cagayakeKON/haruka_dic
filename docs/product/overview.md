# Haruka 产品总览

状态：设计基线，2026-09-22。需求、技术和工程规范已文档化，[新版 HTML 原型](../../prototype/README.md) 已建立；正式 Flutter/Python 应用、基础设施接入及本篇验收目标尚未实现或验证。本文定义产品范围与目标，具体操作以各模块为准，公共字段/协议以契约文档为准。现有原型尚未迁移到本次三类独立流程，不能作为已实现证据。

## 1. 产品定位与已确认边界

Haruka（ハルカ）只适配用户自己的小说、课本和试卷三类材料，将阅读、朗读、解释、收藏、练习、评分与诊断连接成个人语言学习过程。“课本”与“教材”指同一类：

**材料 → 理解（读/听/问）→ 收藏 → 练习 → 评分 → 诊断 → 再练/再读。**

目标是让自己的材料成为持续可用的课程，减少阅读器、闪卡、通用聊天和练习工具之间反复复制、丢失出处和学习记录的问题。

| 已确认约束 | 范围 |
| --- | --- |
| 客户端 | Flutter，Windows、Web、Android |
| 服务端 | Python 前后端分离，复用 MyHome 基础设施，Haruka 业务、账号、数据库、凭据和部署独立 |
| 多用户 | 注册、登录、私有资料库与学习记录；每位用户使用各自填写的 API Key |
| 应用 Agent | Pydantic AI；卡片、题目、评分与诊断使用类型化校验 |
| 朗读 | Gemini TTS 或 OpenRouter TTS；不静默替换为系统 TTS |
| 试卷 | 导入时显式选择试卷模式，整卷作答、交卷后判断/评分与复盘；首版格式范围待确认 |
| 管理与授权 | 管理后台和完整 RBAC，控制两端登录、页面/菜单/按钮、接口、业务动作和数据范围；Flutter Web 管理端是推荐实现 |
| 用户备份恢复 | 仅单词 CSV 导出和导入，不含整库 ZIP、原书/音频打包和数据库恢复界面 |
| 观测 | 前端、正常业务埋点、后端、数据库、AI/TTS 与基础设施日志统一进入 MyHome Alloy/Loki/Grafana |

同一账号三端访问自己的服务端数据；本机存储用于隔离的阅读、已查词句解释和音频副本。未配置 Key 不阻断已授权的登录、基础解析/阅读、已有解释/音频读取、就绪试卷作答/交卷、规则评分和 CSV；需要 AI 的新调用阶段明确保留待处理状态。以上替代旧的无登录、共用资料库和全量备份设想。

## 2. 目标用户与使用场景

主要面向使用自有文本做沉浸阅读的自学者、按学校/自学教材学习并练课后题的学生，以及同时学习多种语言或母语非中文的用户。

典型场景包括读日语小说时查词收藏，再从收藏生成练习；按英语教材的 Unit 阅读并完成原生习题；询问句子语法后继续练习；根据近期错题诊断薄弱点；导入一套试卷模拟考试并在交卷后复盘。PDF、听写和口语等示例只有在对应版本获准后才可用，不改变下述首版边界。

产品不以学校完整 LMS、公开材料社区、视频课/真人外教或儿童专项为主要用户场景，范围外项目见第 8 节。

## 3. 产品原则

1. **材料即课程**：使用用户带来的内容，不强迫走官方课程大纲。
2. **三类分别处理**：小说有专用结构/语言预处理与连续阅读器，课本有单元/内容角色分析与学习页，试卷有题目/计分校验与整卷考试流程。仅复用文件提取、出处等基础能力，不能靠切皮肤适配。
3. **文本可操作**：有权限的词、短语、句和摘录可朗读、解释、收藏、发送给 Agent；考试中按模拟考试规则限制辅助。
4. **保全出处**：收藏、解释和错题保存原文上下文和版本化来源；无法回跳时显示原因和快照，不能伪造关联。
5. **练习来自缺口**：优先使用真实语境、收藏、错题和薄弱点，区分原题、变式与生成例。
6. **Agent 帮助行动**：用证据诊断，提供练习和原文入口；不只输出泛泛鼓励。
7. **语种中立**：界面语言、母语和目标语独立；能力通过语种适配扩展，支持范围和质量逐步验证。

## 4. 产品目标与成功指标

| 目标 | 说明 |
| --- | --- |
| G1 | 常用学习文件在数分钟内成为可学内容，按已支持格式评价 |
| G2 | 阅读/教材界面成为日常入口；试卷具备开考、整卷提交与复盘流程 |
| G3 | 收藏和错题能稳定转成练习 |
| G4 | Agent 能用证据说明薄弱点并发起对应练习 |
| G5 | MVP 的简体中文界面/母语、英语与日语学习体验完整，架构不绑定一种语言 |

| 上线后指标 | 目标/口径 |
| --- | --- |
| 导入成功率 | MD/EPUB ≥ 90%；PDF 的可学文本提取率单独统计 |
| 导入后形成学习行为 | 统计导入后 7 日内至少发生 1 次朗读、1 次解释和 1 次收藏的用户占比；数值目标尚未指定 |
| 收藏/错题转为练习 | 周转化率 ≥ 40% |
| Agent 使用 | 有练习行为用户中的 Agent 周活跃 ≥ 30% |
| 出处可追溯与回跳 | 数据层 100% 可追溯；有权、存在且可精确解析的来源一键回跳成功率目标 100%。已删除、失权或歧义来源必须返回规定的快照/安全状态，不伪造成功 |

学习事实以业务库为准，客户端埋点用于行为与体验分析。指标需定义分母、样本窗口、去重和缺失口径；日志有限留存或离线缺报不能当作零，也不能因补传重复计数。具体采集见 [观测规范](../operations/observability.md)。以上是目标，没有线上数据或实测结论。

## 5. 信息架构与核心旅程

最新视觉方向为年轻化、漂亮、现代美观与杂志式排版；不设“继续阅读 / 最近在读”区域。用户已否定大面积绿色，要求 Primary 配色；当前原型使用白色/浅灰底与蓝色 Primary，具体蓝色色值是暂定解释，不能视为最终视觉规范。

用户端默认书库首页，按权限展示材料列表；无书库权限进入首个可访问页面或受控空状态。用户端不设独立“今日学习/仪表盘”页。管理端有独立 `/admin` 登录、运维概览与管理布局。

| 区域 | 主要入口 |
| --- | --- |
| 账号 | 登录、注册、本人安全与退出 |
| 书库 | 全部/小说/课本/试卷、语言和标题筛选、显式类型选择、材料详情/目录/各自状态 |
| 阅读/教材/试卷 | 按材料类型进入阅读器、单元页，或开考/继续/成绩入口 |
| 收藏 | 单词/短语/句/摘录、标签/来源/掌握度筛选、CSV 与拍照词表 |
| 练习 | 来源与题型选择、智能练习、错题/手动待练、历史与评分 |
| Agent | 对话、类型化卡片、诊断报告与建议动作 |
| 设置 | 个人资料、安全、服务连接、个人模型 Key、语言/阅读/朗读、单词数据、本机缓存 |
| 管理后台 | 概览、用户/会话、角色/权限、两端菜单、注册策略、配额/模型、资源/任务、审计诊断 |

全局选区工具为朗读、解释、收藏、问 Agent，分别检查动作权限。页面隐藏不替代服务端授权；考试作答中不提供解释、问 Agent 或答案提示，交卷后复盘按权限恢复学习工具。

| 旅程 | 用户可得到的结果 | 详细操作 |
| --- | --- | --- |
| 注册并开始学习 | 创建私有账号/资料库，进入有权页面；AI 前配置个人 Key | [账号](../modules/accounts.md)、[设置](../modules/settings.md) |
| 小说导入与阅读 | 选小说，提取章节与正文，预处理语言标注，进入连续阅读器 | [小说](../modules/novels.md)、[共用导入](../modules/materials-reading.md) |
| 课本导入与学习 | 选课本，建立单元/内容角色与习题关联，进入单元学习页 | [课本](../modules/textbooks.md) |
| 阅读中理解与收藏 | 选词句，在浮层/侧栏解释，收藏保留语境与出处 | [AI 与朗读](../modules/ai-speech.md)、[收藏与练习](../modules/vocabulary-practice.md) |
| 收藏/错题到练习 | 按来源出题，逐题反馈，再练错题；自动 SRS 属 P1 | [收藏与练习](../modules/vocabulary-practice.md) |
| Agent 诊断与追问 | 有证据的薄弱点、亮点和下一步；对话继承合法上下文 | [AI 与朗读](../modules/ai-speech.md)、[诊断](../modules/vocabulary-practice.md) |
| 单词迁移 | 全部/筛选单词导出，CSV/拍照先预览后确认 | [收藏与练习](../modules/vocabulary-practice.md)、[CSV 契约](../contracts/vocabulary-csv.md) |
| 导入试卷到复盘 | 校对并确认版本，开考/保存/继续，锁卷后批改与成绩复盘 | [试卷](../modules/exams.md) |
| 退出与换账号 | 撤销/清理当前设备身份，隔离缓存、音频和迟到结果 | [账号](../modules/accounts.md)、[设置](../modules/settings.md) |
| 管理访问权限 | 预览并提交角色/权限/菜单/账号变更，及时生效并审计 | [管理后台](../modules/admin.md) |

## 6. 优先级与版本边界

P0 为 MVP/v0.1，P1 为首个正式增强版本/v0.2，P2 为 v0.3+。业务存在不代表任意账号自动获权；已确认产品能力、推荐实现、待决范围与实测状态分别记录。

OCR已确认统一使用用户配置的视觉模型，拍照识词也走同一识别基础能力；三类材料仍独立校验和使用。可用文本层直接提取无需模型，扫描部分需显式视觉识别意图、本人Key和预算；缺Key不能承诺扫描正文可读。此技术决定不改变下表格式优先级，具体执行见 [视觉OCR](../architecture/vision-recognition.md)。

| 模块 | P0 必须覆盖 | P1 / P2 边界 |
| --- | --- | --- |
| 账号与隔离 | 注册/登录/续期/退出/改密、私有库、三端同账号数据、本人 Key；后台可配注册/审批和安全默认角色 | 具体邀请/邮箱验证/恢复方案仍待决；MyHome SSO 不在范围 |
| 材料公共能力 | MD/EPUB、三类显式选择与独立处理、质量报告、选错类型显式创建新材料重处理、原文件/版本/出处 | P1 小说/课本 PDF/OCR/TXT、普通章节/块校正；P2 三类范围内跨材料检索、可选难度曲线 |
| 小说 | 章节/段落/对话保留、分句/选词辅助、连续横排阅读、目录/字体/主题/选区/朗读高亮、进度/书签/历史 | P1 分页、双语/句级翻译层、阅读热力图；高保真 EPUB 范围待决 |
| 课本 | 单元树、课文/语法/例句/词表/习题角色与关联、专属单元学习页、内容位置/书签/逐题练习 | P1 单元完成度、讲练分屏；缺答案是否导入时预生成仍待决 |
| 收藏与词表 | 四类收藏、语境/出处、笔记/标签/掌握状态、筛选/基础搜索/合并；全部/筛选单词 CSV 往返；单图拍照识词 | P1 多图词表（建议最多 10 张）；照片词表不等同整卷 OCR |
| 普通练习 | 现成教材题重做、真实语境选择/填空/句译生成、逐题提交与规则/AI 评分、错题、历史、待审反馈 | P1 匹配/排序/听写、易混词对比与语法变形、SRS、扩展写作/多句翻译、人工覆盖；P2 口语评分 |
| 试卷 | 显式模式、结构校对、冻结版本、原生答题/答题卡/标记/保存/继续、可选限时、幂等交卷、规则/AI 批改、成绩/错题复盘；基础文本简答/作文 | MD/EPUB 复用；文本 PDF 推荐提前但未确认，扫描 PDF/多图暂按 P1。普通 PDF/OCR 的后续安排不因此整体提前 |
| 解释、Agent 与诊断 | 上下文词/短语/句/摘录解释；WordCard/SentenceCard/GrammarCard，phrase 为 WordCard 子型；多轮会话；7/30 天或本教材报告及出题/原文动作 | P1 每周学习建议、错因深析/对比、ContrastCard/PronunciationCard/ExerciseReviewCard；P2 跨教材能力迁移/考试等级估计、完整计划与日历。独立 Phrase/Diagnosis 卡按后续契约启用 |
| 朗读 | Gemini/OpenRouter TTS、词/句/摘录/章节、播放/暂停/停止、0.7–1.5 倍速、句级片段高亮、有界预取、三端音频复用 | P1 生词减速/重复、先听后显示、收藏列表朗读；P2 跟读另需录音/识别/评价能力 |
| 设置与缓存 | 中文界面/母语与英日学习，独立目标语；模型/声音/解释偏好；查过词句/完整AI解析/TTS自动持久保存与书内索引，不要求收藏；有效租期内已有阅读/解释/音频只读缓存；本机清理 | P1 下载/缓存增强；P2 离线写入和冲突合并另行确认。新语言按验证启用，不承诺MVP同等质量或三语UI |
| 管理与 RBAC | 独立入口、运维概览、用户/会话、角色/继承/allow/deny、两端菜单/动作/字段/接口/范围、授予边界、撤权、审计、安全初始化 | 不增加共享 Key、代登录或私有内容旁路 |
| 日志与埋点 | 三端正常/失败日志、页面/性能/网络/异常、后端/Worker/模型/工具/TTS、ORM/PG/基础设施；统一关联、脱敏、有界补传和账号隔离 | 留存/容量/告警须实测；遥测不是权限、费用或学习事实来源 |

单文件建议上限为 MD/TXT 20 MB、EPUB 50 MB、PDF 80 MB，1 MB = 1,000,000 字节；仅在该格式获准后启用，超限明确报错，试卷图片页数/体积待格式验证。实际部署与解包/像素限制见 [配置与运行](../operations/configuration.md)。

原有“用户可删除 AI 生成错误题”的需求继续保留；当前删除语义与历史版本契约缺口见 [学习模块 §7](../modules/vocabulary-practice.md) 和 [待决清单 OPEN-10](../decisions/pending.md)，不能因本轮重组删除或擅自降为 P1。

## 7. 非功能目标与隐私体验

| 项目 | 目标或必须保持的结果 |
| --- | --- |
| 导入 | MD/EPUB 中位时长 < 30 秒，不含大模型深度抽题；深度分析异步，完成后提示 |
| 阅读 | 已缓存章节打开 < 300 毫秒；未缓存网络加载单独测量，滚动流畅 |
| 解释 | 正常网络下首 token < 3 秒 |
| 客观评分 | 后端规则计算 < 100 毫秒，不含网络往返 |
| 主观评分 | 即时单题 < 8 秒；整卷批改异步显示逐题进度，不套用单题目标 |
| 考试可靠性 | 草稿可区分已保存/未同步，服务端计时，幂等锁卷，失败保留答案，旧场次版本不被改写 |
| 可用性 | AI 故障不阻断已授权的基础阅读/已有音频；后端不可达时限于有效租期内本机缓存；任务可从已提交阶段恢复 |
| 身份与授权 | 两端登录、会话撤销、账号切换、RBAC 与归属隔离有效；管理员受授予边界约束 |
| 权限一致性 | 页面/菜单/按钮/API 同一动作映射；新受保护请求使用新权限，长连接/任务按边界复核，离线撤权限制明确 |
| 隐私 | 私有材料、TLS、密码哈希、按用户加密 Key；秘密不进日志/队列/CSV |
| 观测 | 所有来源进入同一平台，正常事件可查且可关联；采集缺口/丢弃/留存可见，上报不阻塞学习 |
| 单词数据 | 全量单词 CSV 往返；导入失败不破坏已有数据，不恢复原书/音频/学习记录 |
| 可验证性 | 认证/RBAC/双账号、导入抽题、出处、CSV、照片、考试评分、卡片、TTS 缓存和三端流程有有效测试证据 |

性能目标须注明设备、网络、供应商/模型、样本规模与统计分位；当前没有通过数据。运行与验收方法见 [测试策略](../engineering/testing/strategy.md) 和 [交付验收](../delivery/acceptance.md)。

Haruka 不将用户材料用于自身训练。向所选 AI 供应商发送的数据以及该供应商保留/训练政策应明确说明，不能代供应商作未验证保证。用户书中的例句保留来源，AI 自造例句标为生成例。产品尊重版权，不提供公开整书分享；违法内容按安全策略处理，个人试卷模拟和交卷后 AI 批改属于正常学习场景。

## 8. 范围外

- 官方课程/教材内容生产，应用内购买他人版权书。
- 小说、课本、试卷之外的独立材料类型，例如文章、笔记、字幕或“其他/混合”；课本内的摘录/习题只是内容角色，不增加第四种业务流程。
- 学校 LMS、班级/教师端、作业下发、多人考试发布与监考。
- 公开材料市场、社交社区、公开整书分享；视频课程或真人外教为核心的模式。
- 未建设家长监护体系的儿童专项，短视频流、游戏化宠物。
- 保证考试过级或把 AI 等级估计当正式认证。
- MyHome 账号互通/SSO、组织与多人共享资料库。
- 整库 ZIP 备份/恢复、原书/音频打包及非单词数据导出。
- v0.1 完整离线编辑、离线出题/评分、管理端离线访问与冲突合并。

## 9. 风险与对应设计

| 风险 | 必须保留的应对 |
| --- | --- |
| PDF/OCR 质量差、题目缺失/答案错配 | 明确格式范围、质量报告/校对；残缺试卷不能 ready |
| 用户类型选择与内容不符 | 质量提示保留所选类型；显式按目标类型重新处理成新材料，旧出处/进度/答卷保留，不自动换皮肤 |
| 日文分词/活用错误 | 语种适配、用户可扩选，评分采用冻结规范化规则 |
| AI 出题偏离/难度不当 | 真实语境与来源标识，错误题删除需求待补操作契约 |
| 主观评分不稳定 | 冻结 rubric、复核标记、规则优先、程序累计，失败不计零分 |
| 保存/交卷竞争或重评覆盖 | 冻结版本、编辑代次、幂等事务和有效评分历史 |
| AI/TTS 意外费用 | 显式请求与预算、有界分段/预取、结果复用，不无限重试未知结果 |
| 串用数据/权限遗漏/提权 | 归属与缓存分区、默认拒绝、权限版本、授予边界和双账号/角色矩阵 |
| CSV 丢字段或重复 | 版本化协议、可逆转义、预览和重复策略、往返验证 |
| 共享设施影响 MyHome | 独立命名/凭据、用户与全局配额，接入前验证容量 |
| 版权 | 私人书库与单词 CSV 互操作，不做公开整书分享 |
